이 문서와 설정 JSON이 최신 기준이다. v3.1은 이력으로 보존했다. v3.1의 합성 신호·위험 상한·비용 목적식·실행량·주검정은 현재 실행 조건이 아니다. 9월 원본 세 파일은 수정하지 않았다.

02실험을 쉬운 말로 설명하면

AI에게 여러 산업에 돈을 나누어 담는 문제를 준다. 예를 들어 어떤 산업은 평균 수익이 높아 보여도 다른 산업과 늘 같이 떨어진다면, 여러 산업에 나눠 담았다는 이유만으로 위험이 줄지는 않는다. 이 관계를 숫자로 적은 표가 공분산표다. 연구자는 공개된 과거 산업 수익률로 평균 수익과 이 표를 미리 계산한다. AI가 숫자를 만들어 내도록 맡기지 않는다.

같은 문제를 서로 분리된 대화에서 풀게 한다. 한쪽은 처음부터 필요한 표를 받고 계획·초안·검토를 진행한다. 다른 쪽은 같은 평균 수익 전망으로 계획과 초안을 만든 뒤 검토 때 같은 표를 처음 받는다. 마지막에는 두 쪽 모두 같은 자료와 같은 투자 규칙을 알고 있다. 그래서 일찍 받은 정보를 계속 활용하는 방식과, 뒤늦게 받은 정보로 이미 만든 초안을 수정하는 방식의 차이를 볼 수 있다. 단계 수와 검토 기회도 시점 효과의 일부이므로 결과를 순수한 심리적 고착 효과로 단정하지 않는다.

평가용 프로그램은 AI와 별도로 똑같은 식을 풀어 기준 배분을 만든다. AI가 제안한 12개 산업의 비중이 이 기준과 얼마나 맞는지, 정해진 식의 점수가 얼마나 낮아지는지 확인한다. 기준 배분은 앞으로 돈을 가장 많이 벌어 줄 예언이 아니다. 그때 제공한 숫자와 규칙을 충실히 적용했을 때의 답이다. 그래서 실제 미래 수익을 못 맞힌 문제와 주어진 자료조차 활용하지 못한 문제를 분리할 수 있다.

이 계산 실험과 함께 실제 펀드 문서를 읽는 실험도 한다. 공시에서 보고일·보유금액·투자 규정 등을 찾아 정확히 설명하는지, 검색 과정에서 근거를 빠뜨리는지, 근거가 없을 때 없다고 말하는지 본다. 실제 펀드의 현재 비중은 공시 금액으로 계산한다. 금융 모형의 기준 답을 실제 운용사의 의도라고 해석하지 않는다. 문서 검증과 숫자 배분 검증의 결과를 따로 보고한다.

현재는 공개자료를 내려받아 두 목적식의 기준 계산까지 끝낸 상태다. 아직 AI에 질문을 던져 얻은 결과는 없다. 먼저 두 후보 중 연구 목적에 맞는 식을 고른 뒤, 같은 모델·자료·질문 양식을 고정하고 파일럿으로 실행 시간과 실패 양상을 확인한다.

03세 가지 비중과 계산식

비중어떻게 정하나어디에 쓰나
현재 비중 h공시의 보유금액을 산업별로 더해 계산한다. 사람이 목표 숫자를 고르지 않는다.실제 펀드 상태 설명과 향후 재배분 과제. 현재 두 목적식에는 h가 들어가지 않는다.
AI 제안 비중 wAI의 최종 답에서 받는다.평가 대상. 답을 본 뒤 유리하도록 기준식이나 산업 체계를 바꾸지 않는다.
기준 비중 w*동일한 입력과 제약으로 목적식을 계산한다.정보 활용·계산 정확도 비교. 실제 운용사의 정답 또는 미래 수익 정답이 아니다.
Vₖ = 산업 k로 분류된 적격 보유 주식의 공시금액 합계
E_map = Σₖ Vₖ
hₖ = Vₖ / E_map
q_map = E_map / NAV
펀드 전체 순자산 대비 해당 산업 비중 = q_map × hₖ = Vₖ / NAV

이는 분모를 명확히 하기 위한 회계적 산출 정의다. 논문에서 권장한 산업별 비중으로 포장할 수 없다. 매핑 가능한 주식 부분의 합이 100%라는 것과 펀드 전체 자산의 합이 100%라는 것을 구분한다. 현금·파생상품·우선주 등 대상 밖 자산은 별도 집계하고, 적격 주식의 SIC가 없다는 이유로 기타 산업에 넣거나 대상 밖으로 옮기지 않는다.

같은 평균·공분산·제약을 받으면 두 목적식 모두 같은 기준 답을 낸다. 따라서 이 두 모형으로는 출발 비중이 다르다는 이유만으로 펀드마다 다른 최종 답을 강요할 수 없다. 펀드 고유의 제약·전망·거래 비용을 넣어야 하는 연구라면 그 입력과 식을 별도로 근거화해야 한다.

FF49는 별도 산업 체계다. FF49의 비중을 단순히 합쳐 FF12로 바꾸지 않고, 같은 종목의 SIC를 각 체계에 따로 적용한다. 한국어 이름은 설명용이며 자동 분류에는 공식 숫자 구간을 사용한다. SIC 미확인은 결측이다. FF12 Other는 확인된 유효 SIC의 잔여 범주이고 FF49 Other는 별도 명시 범위다.

공식 French 산업 포트폴리오는 Compustat/CRSP SIC를 사용한다. 공개 SEC SIC로 실제 펀드 보유 주식을 연결하면 SEC-SIC 대체 매핑이므로 공식 구성 종목을 완전히 복제했다고 쓰지 않는다. ADR은 예탁은행이 아니라 실제 발행기업을 확인한다. EFS v2 §V-A는 FF49 사용 선례이며, FF49가 이번 과제에 더 좋다는 검증은 아니다.

05목적식 두 후보의 차이

P — 매수만 가능한 최대 샤프비율: 권고

w* = argmax [(μᵀw − r_f) / √(wᵀΣw)]
조건: Σₖwₖ = 1, wₖ ≥ 0
μ = 252 × 직전 60거래일 평균 수익률
Σ = 252 × 같은 60거래일 표본 공분산
r_f = 0.04 (연율)

쉽게 말하면 ‘기본 이자 수익을 넘어서는 기대수익을 위험 한 단위당 얼마나 얻는가’를 가장 크게 하는 배분이다. PortBench v6 Appendix C.1 T5의 식·매수 제약·추정 창·무위험수익률을 가져온다. 연 4%는 논문 실험 상수이며 현재 시장 금리라는 뜻이 아니다. 산업 수익률에는 총수익률을 사용하므로 RF를 먼저 빼고 다시 4%를 빼지 않는다.

252일 연율화는 PortBench의 B.2·C.4 관례를 적용한다. 산술평균과 표본 공분산의 분모 T−1은 이 코드에서 명시한 추정기 구현이며, T5가 최적이라고 검증한 추가 하이퍼파라미터로 주장하지 않는다.

장점은 γ를 따로 고를 필요가 없고 비중이 0~100%로 해석된다는 것이다. 단점은 별도 집중 제한이 없어서 한 산업에 몰릴 수 있다는 것이다. 보기 좋게 20% 상한을 넣으면 새 제약이 되므로 넣지 않는다. FF12로 자산을 대체하고 월말 문제를 구성한 부분은 LIBERA의 적용 설계다.

Q — 공매도를 허용하는 이차효용: 대안

w*γ = argmax [μ̂ᵀw − (γ/2)wᵀΣ̂w], 1ᵀw = 1
γ ∈ {1, 3, 5}
λ = [1ᵀΣ̂⁻¹μ̂ − γ] / [1ᵀΣ̂⁻¹1]
w*γ = Σ̂⁻¹(μ̂ − λ1) / γ

기대수익에서 위험 부담을 뺀 점수를 최대화한다. γ가 크면 위험에 더 큰 감점을 준다. Salcher 외(2026), 식 (6)–(7)·§4·Table 2의 원형을 쓰며, 세 γ를 모두 계산해 임의의 중간값 하나를 정답으로 선택하지 않는다. 입력은 월간 초과수익률의 60개월 추정치이고 이후 36개월은 사후 성과 확인용이다.

양의 정부호 공분산이면 기준 답이 유일하고 직접 계산할 수 있다. 대신 음수 비중과 100%를 넘는 비중을 허용한다. 매수 전용 펀드의 실제 운용 규칙으로 그대로 쓰기 어렵다. 논문식 표본 공분산 모드와 저자 코드의 20% 대각 수축 모드를 따로 계산했다. 후자의 0.2는 논문 본문 고정값이 아니라 2026-09-17 저자 코드의 구현값이므로 엄격한 ‘paper 직접 수치’ 권고에는 포함하지 않는다.

두 후보를 혼합하지 않는다. Q에 매수 제약을 추가하거나 P에 거래 비용·현재 위험 상한을 붙이면 새 조합이다. 그 조합이 필요한 이유와 추가 출처를 확보한 뒤 별도 실험으로 등록한다.

모든 임의 선택을 논문 인용으로 없앨 수는 없다. 연구질문과 처치를 새로 만드는 순간 연구자 설계가 생긴다. 여기서는 숫자의 출처를 강제로 붙이는 대신, 직접 차용·계산 결과·새 적용을 명시하고 근거 없는 금융 상수를 비활성화한다.

실제 계산이 선택에 주는 정보

Q의 논문식 모드에서는 γ=1·3·5 모두 모든 창에 음수 비중이 있었다. 매수와 공매도 비중의 절댓값을 더한 총노출의 평균은 각각 80.62배·26.98배·16.34배였다. 이는 본 공개자료로 직접 계산한 결과이며 논문에 보고된 수치를 인용한 것이 아니다. 일반적인 매수 전용 산업 배분을 연구하려면 P를 택하는 편이 질문과 맞는다.

P도 분산투자를 보장하지 않는다. 132개 중 34개에서 한 산업의 비중이 100%였고, 마지막 2025-12-31 문제의 기준 답은 Hlth 100%였다. 이 날짜는 목록의 끝이라는 이유로 제시했으며 성과가 좋은 예를 고른 것이 아니다. 실제 투자 권고가 아니라 해당 과거 60일 입력과 식의 계산 결과다. 산업별 상한이 꼭 필요한 연구라면 상한 근거를 가진 다른 과제로 정해야 한다.

소수점 허용오차와 최적화 반복 제한은 프로그램의 수치 구현 설정이다. 금융 실험의 효과를 정하는 논문 조건으로 취급하지 않는다. 검증은 부동소수점 계산의 잔차 확인이며 기계 증명은 아니다.

다시 계산하는 방법

python research/prepare_public_inputs.py --offline
python research/compute_portbench_reference.py
python research/compute_paper_reference.py

--offline은 보존한 원본 해시를 확인해 같은 자료를 다시 처리한다. 새 다운로드는 원자료 수정 여부가 생길 수 있으므로 새 버전으로 관리한다.

원본 ZIP, 공식 페이지에서 확인한 내려받기 주소, 수집 UTC 시각, SHA256을 함께 보존한다. 월별 자료의 첫 value-weighted 수익률 표만 읽고 퍼센트를 소수로 변환한다. 결측 표시는 숫자 수익률로 쓰지 않는다. Q에서는 월별 RF를 한 번 차감하고 P에서는 총수익률에 T5의 연 4%를 적용한다.

현재 French 파일은 다운로드 시점의 수정 자료다. 논문 작성 시점 파일과의 값 일치 또는 과거 당시 이용 가능했던 자료라는 성질을 보장하지 않는다. 이 자료로 만드는 것은 공개자료 기반 계산 검증이며 실시간 예측 성과 주장은 하지 않는다.

실제 펀드의 현재 비중은 아직 계산 완료가 아니다. SEC 공시 주소는 확인했지만 로컬 자동 다운로드 시 HTTP 403을 받았다. 원문 전체 확보·발행기업 연결·SIC 매핑·금액 대사가 남아 있다. 그 부분을 임의 비중으로 대체하지 않았다.

08선택 후 실행할 조건과 평가

권고 입력 실험에서는 각 상황의 평균 수익 벡터를 모든 조건에 제공하고, 동일한 공분산표를 EARLY는 계획부터, MID는 초안부터, LATE는 검토부터 보여준다. NO-COV는 끝까지 받지 않는다. 서로 다른 대화로 실행하고 같은 상황·모델·식·최종 출력 형식을 맞춘다. 공분산을 받기 전 답에는 정보 부족과 유보를 허용한다. 누락된 표를 사실인 것처럼 생성하는지는 별도로 기록한다.

각 대화의 모델 응답은 계획, 초안 배분, 근거 점검, 최종 배분이다. 근거 점검 뒤 모든 조건에 동일한 형식·단위 검사 결과만 제공할 수 있다. 최적 비중을 알려 주거나 모델의 비중을 자동으로 수리하지 않는다. 마지막 자료만 받고 한 번 답하는 FRESH도 비교하면 이전 초안이 있는 과정과의 차이를 진단할 수 있다. 이 4응답 구성은 LIBERA의 업무 흐름 정의다.

코사인 유사도는 비중 전체를 같은 배수로 늘려도 바뀌지 않는다. 따라서 비중 합계나 매수 제약을 어긴 답을 높은 유사도만으로 성공 처리하지 않는다. 형식은 읽히지만 제약을 위반한 답의 주평가 처리 규칙은 파일럿 전에 동결해야 하며, 현재 보조 코드에는 원시 점수와 제약 위반을 함께 보존한다.

P를 택하면 T5의 기준 비중과 코사인 유사도를 원 논문 점수로 남긴다. 함께 비중 합계·음수 위반, 해석 가능한 답의 비율, 주어진 μ·Σ 아래 샤프비율 차이를 보고한다. 최적화 프로그램이 실패해 균등 비중으로 대체한 경우는 논문의 fallback으로 표시하고 진짜 최적해라고 부르지 않는다. AI의 무응답·형식 오류는 T5 점수 0으로 남기며 성공한 응답만 골라 비교하지 않는다.

Q 선택 시 입력에 대한 손실:
Uγ(w*) − Uγ(w) = (γ/2)(w − w*)ᵀΣ̂(w − w*) ≥ 0
적용 조건: w와 w* 모두 비중 합계 1, 동일한 μ̂·Σ̂·γ

Q의 손실식은 이차 목적식에서 유도되는 항등식이다. 논문의 별도 검정 통계량을 그대로 가져온 것은 아니다. 미래 36개월로 계산한 완전예지 배분을 AI에 주지 않으며, 그것을 사용한 사후 성과와 입력 충실도 점수를 구분한다. γ별 결과를 따로 보고 임의 가중평균으로 합치지 않는다.

실제 문서 A/C 과제는 공개문서의 사실·규정·근거 확인을 유지한다. A와 C는 서로 다른 공시 시점이며 C에서 검색기나 질문을 고치지 않는다. 필요한 구절을 직접 준 경우와 검색기가 찾은 경우를 비교해 검색 실패와 활용 실패를 구분한다. 기존 개발용 검색 후보와 원문 접근 규칙은 JSON에 보존했지만, 이번 숫자 배분 과제의 점수와 합쳐 하나의 성적을 만들지 않는다.

겹치는 자료 창을 독립 표본으로 세지 않는다. Q의 625개 창과 P의 132개 월말은 기준 계산 문제 목록이다. 현재 계산에는 AI 응답·효과 크기·p값이 없다. 본실험 표본, 시계열 의존성 처리, 반복 실행의 불확실성은 선택한 금융 모듈·평가 범위·파일럿에 맞춰 별도 동결한다. v3.1의 독립 합성 상황용 검정식을 이 목록에 그대로 적용하지 않는다.
