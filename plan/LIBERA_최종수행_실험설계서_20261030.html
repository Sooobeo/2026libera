05 · SCENARIOS합성 전망과 상황 선정

실제 보유상태와 위험척도 위에 공통 시장 전망과 펀드별 추가 전망을 합성했다. 공통 전망 y는 모든 조건에 제공하고, 펀드별 전망 xᵢ는 해당 펀드의 검색 패킷을 통해 조건별 시점에 제공했다. 합성 전망은 통제 실험을 위한 관측값이다.

θ ~ N(m₀, V₀), V₀ = Σ / 12 y = θ + ε₀, ε₀ ~ N(0, V₀) xᵢ = θ + εᵢ, εᵢ ~ N(0, V₀ / r)

θ를 조건으로 관측 오차는 서로 독립이다. θ는 상황 생성에만 사용하며 모델이나 사후 기대수익 계산에 직접 제공하지 않는다. 높은 정밀도 r=2에서는 낮은 정밀도 r=0.5보다 오차 공분산이 작다.

원래 seed 2001로 생성한 상황 중 각 정밀도의 앞선 다섯 ID를 결과 확인 전에 선택했다. 새로 추출하지 않고 기존 생성값을 유지했으며, seed 5001의 원래 실행 순서를 선택된 조건으로 걸러 사용했다. 각 상황 안에서는 펀드·조건 간 공통 입력을 고정했다.

두 정밀도는 서로 다른 상황 추출값을 사용한다. 따라서 같은 상황에 r만 바꾼 짝 비교가 아니라, 각 정밀도 상황군 안의 R0~R3 비교와 전체 평균을 보고한다.

전체 재현에 필요한 로컬 보존 자료

완료 실행의 prepared_inputs.json, 검색 패킷, 원시 응답·HTTP 기록, 복구 이력과 모델 파일은 로컬에 보존돼 있다. 이 자료 중 일부는 파일 수와 용량 때문에 Git에서 제외했다. Git의 요약·코드만으로 저장되지 않은 원응답까지 복원되는 것은 아니므로, 같은 실행을 검토할 때에는 해당 로컬 보존 자료를 함께 사용한다.
