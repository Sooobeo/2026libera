공통 AI의 기관별 공개 투자판단 반영
초안 전후 근거 제공을 비교하는 축소 실험계획

상경·경영학술제 텀페이퍼용 · 설계 개정안 · 본실험 미실행

2개 기관 자료 × 2개 제공 절차 × 2단계 = 본실험 최대 8회 생성.
기관별 차이·11개 산업·근거와 비중의 연결은 유지한다. 4단계의 반복 출력과 최종안 뒤 추가 수정은 제거한다. 최종 단계에는 양쪽 모두 동일한 기관 자료를 다시 제공한다.

이 문서는 실행 가능한 비교를 위한 새 설계다. 질문과 관측의 연결을 명시하지만, 모델의 성공·통계적 유의성·장치 안정성을 보장하지 않는다. 현재 확인한 것은 문헌과 오프라인 입력 구조이며, v4.9 모델 호출은 0회다.

쉽게 보는 실험논문과의 연결비교 조건산업·자료평가축소 효과문헌 근거진행 조건

1. 실제로 무엇을 하는가

같은 AI에게 미국 주식시장의 11개 산업에 투자금을 어떻게 나눌지 제안하게 한다. 시장자료는 모든 경우에 같다. 달라지는 것은 Fidelity와 UBS의 공개 산업전망 중 어느 자료를 받는지, 그리고 그 자료를 초안을 만들기 전부터 받는지 아니면 초안 이후에 처음 받는지다.

E 조건은 시장자료와 해당 기관 자료를 함께 읽고 첫 배분안과 이유를 작성한다. 계산기가 실제 제출한 비중의 합계와 역사적 위험 등을 검사한다. AI는 그 결과와 다시 제공된 같은 기관 자료를 읽고 최종안을 낸다. L 조건은 기관을 모르는 상태에서 시장자료로 초안을 만든다. 그 다음 같은 방식의 계산 결과와 해당 기관 자료를 처음 받아 최종안을 낸다. 각 사례는 새 대화로 시작하고 다른 기관의 답변을 보지 않는다.

최종적으로 “기관 문구를 외웠는가”만 보는 것이 아니다. 기관이 강조한 이유를 정확히 이해했는지, 그 이유를 받아들이거나 다른 근거와 비교했는지, 설명한 선택이 실제 비중에 들어갔는지 확인한다. 기관 의견과 다르게 배분해도 근거 있는 설명이라면 무조건 오답으로 처리하지 않는다.

예를 들어 유틸리티에 대해 한 자료가 비싼 가치평가를 우려하고 다른 자료가 방어력과 AI 관련 수요를 강조한다면, 모델이 이 차이를 읽고 어떻게 저울질했는지 본다. 두 자료에 “정답 비중 5%와 10%”가 있다고 가정하지 않는다. 이 예시는 결과를 보고 고른 산업이 아니며, 평가에는 11개 산업 모두 포함한다.

2. 소논문 주제와 무엇이 연결되는가

논문의 논점실험에서 관측하는 것해석의 한계
공통 AI를 쓰면 조직별 판단 맥락이 사라지는가같은 모델·시장자료에 서로 다른 공개 산업판단을 넣고, 출처→해석→설명→비중의 연결을 비교한다.실제 기관 내부 목적·보유종목·직원 행동은 관측하지 않는다.
업무 과정의 어디에서 근거를 제공해야 하는가초안 전 제공 E와 초안 후 첫 제공 L을 같은 최종 정보 아래 비교한다.초기 노출·자체 초안·노출 횟수의 묶음이다. 순수한 기억이나 앵커링 효과로 단정하지 않는다.
AI 사용의 조직적 대응은 무엇인가근거 해석, 설명과 행동의 불일치, 계산 오류 중 어느 지점이 문제인지 구분한다.관측된 문제에 맞는 검토 절차를 제안할 수 있으나 비용효과나 수익률 개선은 검증하지 않는다.
원제안서의 시장 전체 동질화·금융안정 문제문헌상 문제의식과 후속 연구로 연결한다.이번 작은 문서 실험으로 부정적 동질화, 필요한 다양성의 상실, 시장 손실을 직접 입증하지 않는다.

수정할 논문 제목: 「공통 생성형 AI의 기관별 공개 투자판단 반영: 초안 전후 근거 제공을 비교한 산업배분 사례연구」. 기존 v4.8.1의 공개 판단 보존 질문은 유지하되, 네 단계 분산 활용이나 실제 RAG 검색을 검증했다는 문장은 사용하지 않는다. 원제안서의 더 강한 시장 동질화 가설을 그대로 실증했다고 제시하려면 별도 통제과제와 자료가 필요하다.

학술제의 경제·조직 문제와 대응이라는 방향에는, 조직의 판단 근거가 AI 권고안으로 전달되는 과정을 점검한다는 방식으로 연결한다. 제출 개요의 추정 배점은 실험 점수로 사용하지 않는다.

3. 비교 조건과 진행 순서

사례1단계 D0: 초안2단계 F0: 첫 최종안
Fidelity–E공통 시장자료 + Fidelity 자료자기 초안 + 실제 계산 결과 + Fidelity 자료 재제공
Fidelity–L공통 시장자료만. 기관 이름도 숨김.자기 초안 + 실제 계산 결과 + Fidelity 자료 첫 제공
UBS–E공통 시장자료 + UBS 자료자기 초안 + 실제 계산 결과 + UBS 자료 재제공
UBS–L공통 시장자료만. 기관 이름도 숨김.자기 초안 + 실제 계산 결과 + UBS 자료 첫 제공

최종 단계의 지시문·출력 형식·해당 기관 패킷·패킷 위치는 E/L에서 같다. 여기서 위치는 마지막 메시지의 같은 구성 순서를 뜻하며 절대 토큰 위치까지 같다는 의미는 아니다. 자기 초안과 그 계산 결과는 각 사례에서 나온 그대로 유지한다. 따라서 최종 자료는 같지만 이전에 자료를 활용할 기회와 생성된 이력은 다르다. 이는 자료 제공 절차의 비교이며 완전히 동일한 입력 길이나 동일 계산량을 뜻하지 않는다.

L 초안은 서로 재사용하지 않는다. 기관당 두 조건을 짝지어 분석하되 네 사례를 독립 기관 네 곳으로 세지 않는다. 실행 순서는 본실험 전에 기록된 난수로 정하고, 사례마다 대화 상태를 분리한다. 순서·seed·모델 버전은 기록하되 결정적 설정이 GPU에서 바이트 단위 동일 출력을 보장한다고 쓰지 않는다.

계산기는 대조군이 아니다. 양쪽에 동일하게 제공하는 지원 도구다. 모델이 낸 비중의 합계·범위·위험·기준 대비 차이만 계산한다. 전략을 대신 정하거나 비중을 정규화하거나 숨겨진 기관 정답을 주지 않는다. 실제 대조는 E와 L이다.

새 결과 이름은 D0/F0다. 기존 R1/R4·C0/C1/C2와 섞지 않는다. F0 이후 추가 답변·자동 재시도·가장 잘 나온 답변 선택은 없다. 초안의 산술 오류는 그대로 피드백할 수 있지만, 초안 자체의 전송 실패로 필요한 이력이 없으면 그 사례의 최종 단계도 미시도로 기록한다.

4. 어떤 산업과 자료를 쓰는가

투자 대상은 GICS 11개 산업 바구니다. 에너지, 소재, 산업재, 경기소비재, 필수소비재, 헬스케어, 금융, 정보기술, 커뮤니케이션 서비스, 유틸리티, 부동산을 모두 포함한다. 개별 종목 선택이나 주식·채권·현금 전체 배분을 평가하지 않는다. 기존 공개 산업 ETF 시장자료와 공통 기준비중을 유지한다.

구분자료사용 원칙

공통 시장자료기존 2026-07-17 기준, 마지막 가격 07-16, 60개 일간 수익률 관측기존 자료를 재사용한다. 수집·정정 이력 때문에 당시 실거래 재현으로 해석하지 않는다.
기준 포트폴리오기존 공개 S&P 500 산업 비중합계 99.9%의 공시 원본과 연구용 정규화 기준을 구분한다. 모델 답변을 정규화하는 것은 아니다.
원문 접근공개 PDF, 페이지 위치, 원래 등급, 기존 연구자 요약 패킷유료 단말·내부 투자지침을 요구하지 않는다. 전체 원문 독해나 자동 검색 실험으로 확대하지 않는다.

Fidelity의 Overweight와 UBS의 Attractive는 같은 숫자 척도가 아니다. 기관 간 평가 어휘의 차이만으로 견해 충돌을 확정하지 않는다. 본실험 전에 모든 산업에 대해 ‘실질적 차이 근거 있음 / 유사성 근거 있음 / 척도 차이로 직접 비교 곤란 / 근거 부족 / 불확실’을 기록한다. 특정 산업의 근거가 없으면 없다고 남긴다.

유틸리티의 대비는 사전 검토 후보다. Fidelity Q3의 3쪽 가치평가 우려와 UBS July의 21쪽 방어력·AI 관련 설명을 비교할 수 있다. 다만 패킷 전사와 척도 해석의 독립 사람 검토는 아직 남아 있다. 산업재·경기소비재처럼 양쪽 모두 긍정적이지만 이유가 다른 산업도 그대로 남겨, 차이만 강제로 만들어내지 않는다.

5. 출력은 짧게 하되 판단은 남긴다

기존에는 산업 해석 목록과 배분 목록에서 긴 설명이 반복됐다. 새 출력은 산업별 한 행에 정보를 모은다. 각 행에는 산업 코드, 원문 등급, 원문 의미, 원문 근거 ID, 의견 수용·수정·이탈 여부, 실제 비중, 배분 이유와 그 근거 ID를 구분해 둔다. 공통 항목으로 대안·위험·미해결 사항·명시적 수치 제약을 남긴다.

줄이는 것은 중복 서술과 메타데이터다. 근거와 다른 의견을 선택한 이유, 대안 간 비교, 불확실성은 지우지 않는다. 단어 수나 문장 수를 근거 없이 제한하지 않으며, 짧게 답했다는 이유로 높은 점수를 주지 않는다. 자료를 받지 않은 L 초안은 기관 등급을 추측하지 않고 null / not_available로 표시한다.

출력 스키마만으로 산업 코드 중복이나 L 초안의 기관정보 금지가 모두 강제되지는 않는다. 실행기에는 11개 고유 코드·유한 수치·단계별 출처·근거 가시성 검증과 새 출력 형식의 계산기 연결을 별도로 구현해야 한다. 현재는 그 요구를 정한 설계 단계다.

공개 입력은 같은 값·단위·날짜·근거 ID를 표의 공통 열로 묶는 방식으로 압축했다. 모든 원래 필드로 복원되는지 검사했다. 이 검사는 정보 보존을 확인하며, 표가 모델에게 똑같이 이해된다는 보장은 아니다. 양쪽에 동일한 표현을 쓰고 예비실험에서 누락·오독을 확인한다.

6. 무엇을 평가하고 어떻게 해석하는가

평가 축확인 내용하지 않는 해석
사실·출처 충실성기관, 산업, 원문 등급, 원문이 실제로 든 이유, 날짜·단위·수치근거 ID가 있다는 이유만으로 내용까지 옳다고 판정하지 않는다.
근거→판단→행동 연결의견을 수용·유보·수정·거절한 이유와 실제 비중·초안 대비 변화가 맞는지원문 등급 복사, 배분 다양성, 근거 없는 차이를 성공으로 세지 않는다.
실행 가능성11개 산업의 누락·중복, 유한 비중, 합계, 음수, 명시적 제약계산기의 자동 보정 결과를 모델의 원래 성공으로 바꾸지 않는다.
완료·비용예정·시도·완료·읽을 수 있음·유효 배분 건수, 토큰·시간·오류완료된 사례만 남겨 전체 성공률을 높이지 않는다.

정성 평가는 ‘연결 지지됨 / 근거 부족 또는 모순 / 미해결 / 누락·판정 불가’를 행별로 기록하고 원문 인용 위치와 이유를 남긴다. 사실·전략 연결·산술을 임의 가중합하지 않는다. 기관 의견과 다르더라도 올바르게 이해하고 경쟁 근거를 설명하면 지지 가능한 판단으로 평가할 수 있다. 이것은 실제 투자수익의 우수성 판정이 아니다.

두 사람은 가능한 범위에서 E/L 표시를 가린 상태로 먼저 따로 검토하고, 의견 불일치를 보존한 뒤 조정한다. 내용으로 조건이 드러날 수 있어 완전한 눈가림이라고 주장하지 않는다. AI의 세 차례 자체검토는 이 사람 검토를 대체하지 않는다.

배분 거리: TV(wᴀ, wʙ) = ½ Σₛ |wᴀₛ − wʙₛ|
자료별 절차 대비: 같은 기관의 E와 L 비교

거리식은 유효한 두 원배분 사이의 차이를 설명한다. 기관의 정답 배분과의 오차가 아니다. E에서 기관 간 거리가 더 커졌어도 근거와 선택의 연결이 나쁘면 개선이라고 하지 않는다. 비중이 같아도 서로 다른 근거를 충실히 검토한 결과일 수 있다.

2개 자료·2조건·2단계·8호출은 자료 범위와 비교 논리에서 나온 연구자 선택이다. 11산업은 기존 GICS 분류다. 출력 상한 8,192는 PortBench에서 이전한 기존 후보이며, 실제 필요한 길이를 보증하지 않는다. FinVector의 700은 이 출력 계약에 적용하지 않는다. temperature 0·thinking 비활성·seed 3407은 원논문과 실행기 차이를 구분해 유지한다. 합계 허용오차 10⁻⁶와 문맥·스레드·시간 제한은 수치·운영 설정이며 논문의 행동 기준으로 꾸미지 않는다.

새 문맥 상한이나 설명 길이를 지금 임의로 정하지 않는다. 필요한 모든 이력과 허용 출력이 들어가는지를 실제 모델 토큰화로 검사하고, 잘림 없이 작동하는 설정을 본실험 전에 고정한다. 이때 변경한 설정은 모든 조건에 동일하게 적용한다.
