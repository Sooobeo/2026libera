1. 연구방향과 논문에 주는 의미

선택 원칙: 비교 가능성, 재현성, 자동 평가 가능성, 학생 팀의 실행 비용을 함께 고려했다. 아래 선택은 이 목적에 맞춘 권고안이며 실험으로 입증된 보편적 최적값은 아니다.

청록색 토글 · 설계 확정 금색 토글 · 운영 확인

연구의 중심 질문: 서로 다른 펀드가 같은 GenAI를 투자전략 설계 업무에 쓰면, 펀드별로 필요한 판단 차이가 줄어드는가? 펀드별 근거를 업무의 어느 단계부터 검색해 제공하면 그 차이와 판단 품질이 회복되는가?

분석 대상은 미국 액티브 주식형 펀드의 주식 부문 내 12개 산업 배분이다. AI가 직접 최종 비중을 정한다. 평가자는 각 펀드의 정보와 명시된 과제에 맞는 기준배분을 별도로 계산한다. 정보의 누락·출처 정확성은 동질화의 경로를 설명하는 보조지표로 둔다.

연구질문실제로 비교할 것
RQ1 · 필요한 차이의 소실서로 다른 보유상태·운용조건·추가정보를 가진 펀드에 같은 LLM을 사용했을 때, 기준상 필요한 배분 차이가 줄거나 같은 사실·제약을 함께 놓치는가?
RQ2 · RAG의 완화효과펀드별 근거를 검색해 제공하면 필요한 차이와 함께 사실 정확성·제약 준수·기준배분 대비 품질이 좋아지는가?
RQ3 · 최초 제공 시점계획, 배분안 구성, 점검·수정 중 어느 단계부터 근거를 제공하고 이후에도 유지해야 효과가 나타나는가? 새 문서와 실제 검색에서도 유지되는가?

논문의 기여: 결과가 비슷하다는 관찰에서 한 걸음 더 나아가, 그 상황에서 필요한 차이가 얼마나 사라졌는지를 측정하고, 어느 업무 단계에 근거를 넣는 정책이 도움이 되는지를 실험으로 비교한다. Hansen과 Lee의 금융 의사결정 연구를 문제 배경으로 삼되, 이 논문은 다단계 펀드 배분 업무에서 정보 제공 시점의 효과를 검증한다. [R1]

가설은 방향을 미리 정한 검증 대상이다. H1: LLM 결과에 기준보다 작은 펀드 간 배분 차이가 나타날 수 있다. H2: 추가 근거 제공은 그 차이와 품질을 개선할 수 있다. H3: 최초 제공 시점에 따라 효과가 다를 수 있다. 조기 제공이 항상 우월하다는 결론은 미리 정하지 않는다.

이번 개정(v2.1): 3단계 업무·원 연구질문을 유지하고, 16개 선택 토글 중 13개를 근거 있는 설계 결정으로 구체화했다. 나머지 3개는 검토자 배정·API 지출 가능액·공개 일정에 대한 운영 확인이다. “확정”은 설계값을 뜻하며 자료 추출·실험 실행 완료를 뜻하지 않는다.

2. 전체 실험 구조: A · B · C

구분무엇을 하는가논문에서 맡는 역할
A · 실제자료 보강실제 펀드 공시와 보유내역으로 펀드 조건·근거를 구성하고, 사실 반영·제약 준수·배분 변화를 측정한다.현실 자료와 업무의 연결. 미래의 유일한 정답 비중을 부여하지 않는다.
B · 핵심 통제실험현실 자료에 연결된 보유상태·위험척도를 고정하고, 공통 전망과 펀드별 추가 전망을 수리모형에서 생성한다.필요한 차이, 과잉수렴, 판단 손실, RAG 최초 제공 시점의 효과를 식별한다.
C · 검색 구현 확인개발에 쓰지 않은 문서·시점으로 검색을 다시 수행하고 같은 3단계 업무를 실행한다.새 자료에서도 검색·근거 활용 효과가 재현되는지 확인한다.

실행은 자료·정답표 구축 → B 파일럿 → 설정 동결 → B 본실험 → A·C 적용 순서다. B에서 만든 평가 기준을 실제자료의 투자 성과 정답으로 옮기지 않는다.

설계 확정 · 자료 종류와 개발·평가·보류 기간

개발: 보유 기준 2025-09-30, 공개일 2025-12-31 이하 자료. A: 2025-12-31 보유, 공개일 2026-03-31 이하 자료. C: 2026-03-31 보유, 공개일 2026-06-30 이하 자료. 각 기간의 전체 보유표, 투자설명서의 운용목표·주요 전략·주요 위험, 공식 운용보고서의 시장·업종 논평을 사용한다.

포트폴리오와 무관한 서명·수수료 예시·일반 세무 안내는 사전 문서 규칙으로 코퍼스에서 제외한다. 적격 절의 원문은 전부 보존한다. C에는 새 문서를 색인하고 검색부터 다시 실행한다. SEC 데이터의 분기는 제출 분기이므로 보고 기준일과 별도로 필터링한다. [D1] [D3] [D4] [D5] [D6]

선택 이유: 같은 펀드의 분기 간 문서로 실제자료 검증을 구성하면 신규 펀드 추가 없이 보류 자료 검증을 수행할 수 있다. 아직 모든 원문을 추출·대조한 상태는 아니며, 누락 문서는 정해진 자료 수집 규칙으로 확인한다.

3.2 자료를 가져오는 순서

우선 SEC의 2026 Q1 N-PORT 묶음에서 CIK·series_id·보고 기준일 2025-12-31로 필터링한다. 일치하는 공개 NPORT-P 원문을 대조하고, 완전 보유표 확인·보완에는 표의 N-CSR Item 7 또는 NPORT-EX를 사용한다. N-PORT는 구조화 데이터 추출의 우선 경로이고, 전체 보유표가 포함된 공시를 교차 확인 자료로 둔다. Top 10 보유종목만으로 h를 만들지 않는다. [D1]

분류 가능한 주식 평가액을 합산해 12산업 h의 합을 1로 둔다. 그 주식 부문이 전체 펀드에서 차지하는 비중 q도 저장한다. 최종 전체 펀드 노출은 q×w와 고정 자산으로 복원해 표시한다. 분류하지 못한 주식과 현금·기타 자산을 사라진 것처럼 처리하지 않는다.

설계 확정 · SIC 매핑·미분류 자산·제약 적용

식별: CUSIP·ISIN·LEI와 발행사명을 이용해 발행사 CIK를 연결한다. 명확한 일치만 자동 승인하고, 혼동되는 이름을 LLM 추측으로 채우지 않는다. 기준시점까지 제출된 기업 공시의 SIC를 French 12산업 규칙에 연결한다. ADR은 발행사 기준으로 분류한다. [D2] [D7]

미분류 처리: SIC를 확인하지 못한 주식, 비상장·비공개 종목, 기타 자산은 원래 비중에 고정한다. 분류 가능한 주식만 12산업 벡터로 정규화한다. 주식 평가액의 90% 이상이 분류되어야 본 분석에 사용한다. 90%는 본 연구의 자료 품질 기준이며 문헌의 규정은 아니다. 전체 비중과 분류율을 함께 보고한다.

제약: B의 기본 제약은 공매도 금지, 비중 합 1, 기존 분산 이하이다. 공식 제약은 해당 산업 비중 과제에 정확히 표현할 수 있을 때만 추가한다. 종목 수·종목 집중도·해외 비중·성장주 요건을 산업 한도로 대신하지 않는다.

3.3 시점과 위험척도

보유 기준일 H와 자료 공개 마감일 T₀를 분리한다. B는 H의 펀드 상태를 출발 프로필로 사용하는 통제 실험이며, T₀에 실제 펀드를 예측 운용하는 백테스트가 아니다. 입력 원문은 T₀까지 공개된 자료로 제한한다.

설계 확정 · 기준시점·월간 자료·공분산

기본 보유 기준일 2025-12-31, 공시 입력 마감일 T₀=2026-03-31. Σ와 m₀는 2016-01~2025-12의 120개 월로 계산한다. French 12 Industry Portfolios의 배당 포함 가치가중 월간 수익률을 사용하고 퍼센트 단위 값을 100으로 나누어 소수 수익률로 바꾼 뒤 계산한다. Σ는 Ledoit–Wolf 수축 추정이다. [D2] [D8] [R4]

일간 자료와 월간 자료를 섞지 않고, 월·산업이 하나라도 결측이면 임의 보간하지 않고 원자료를 점검한다. 사용 파일은 하나의 CIZ 계열 릴리스로 통일해 FIZ와 이어 붙이지 않는다. 파일명·다운로드일·SHA-256을 실행 시 기록한다.

역사 수익률은 현재 취득한 고정 버전으로 생성기의 규모를 보정하는 자료다. 해당 파일이 과거 T₀ 당시의 원본 빈티지라고 주장하지 않는다. 120개월은 충분한 관측치와 작업 범위를 고려한 연구 선택이다.

11. 논문식 분석 계획

독립 표본 단위는 상황이다. 같은 상황의 펀드·조건·API 반복·x 교체 짝을 함께 묶는다. 각 반복에서 지표를 계산한 뒤 상황별로 평균한다. 먼저 비중을 평균하고 거리를 계산하는 방식은 사용하지 않는다. 군집 상관을 고려하는 원칙은 Cameron과 Miller에 근거한다. [R10]

설계 확정 · 대응 t 검정·군집 bootstrap·Holm

상황마다 반복별 지표를 먼저 계산하고 펀드·쌍·반복을 집계한다. 조건 차이의 평균은 상황 단위 대응 t 검정으로 검정한다. R1–R2·R1–R3·R2–R3 × G·regret의 6개 양측 검정에 Holm, family α=0.05를 적용한다. [R10] [R11]

95% percentile bootstrap 신뢰구간은 10,000회, 정밀도별 20개 상황을 층 안에서 복원추출해 계산한다. 펀드·반복·조건·짝은 해당 상황과 함께 이동한다. 이 구간은 개별 구간이며 다중 비교 보정 구간으로 부르지 않는다. 검정의 유의성 판단은 Holm 보정 p값을 따른다.

주지표 비교는 두 조건 모두 같은 펀드·반복에 유효값이 있는 상황에서 계산하고 완전 사례 수를 보고한다. 한 조건의 실패를 지표 0으로 대체하지 않는다. 개별 정밀도별 검정과 R0·C-context 비교는 보조분석으로 표시한다.

13. 설명 주석

  1. 표본 수와 운용방식. “4펀드”는 자료 접근성과 비교 가능성으로 선정한 목적표집 규모다. 실제 펀드의 배분을 모사한다는 뜻은 아니며, 공시로 관측 가능한 출발 상태를 과제의 입력으로 사용한다.

  3. 고정 코퍼스·고정 패킷·실제 RAG. 고정 코퍼스는 검색 대상 문서 집합이고, 패킷은 그 집합에서 실제 검색해 얻은 문단이다. 같은 패킷의 재생은 시점 효과를 통제하기 위한 것이다. RAG 여부와 모델을 하나/여럿 쓰는지는 별개다.
  4. 전체정보 기준과 가용정보 기준. 전체정보 기준은 자료 제공·검색·활용을 합친 업무 성능을 평가한다. 가용정보 기준은 실제로 전달된 관측값만 사용하며, 부분 관측이면 해당 좌표와 관측 공분산을 사용한 조건부 정규 갱신을 계산한다. R0는 y만으로 갱신한다.
  5. 설계 결정과 검증 결과. 4펀드, 60상황, 2반복, 120개월, V₀=Σ/12, r 격자, 검색 400/50토큰·top-4, 감사 10%·20필드는 본 연구가 선택한 설정이다. 문헌은 방법의 근거이고 모든 수치를 권고한 것은 아니다. 토글에 확정한 설정은 본실험 전에 기록하고, 기술적 문제로 바꾸면 변경 이력을 남긴다.
  6. 토글 상태. 청록색은 지금 확정한 설계값·자료 경로·선택 이유이며, 금색은 담당자·지출 가능액·일정의 운영 확인이다. 문서를 열어 값을 입력해도 자동 저장되는 앱은 아니다. 인쇄할 때는 모든 주석을 펼친다.

15. 제한사항 및 유의사항

  1. 연구 범위. 동일 LLM을 사용한 통제 과제의 결과다. 실제 금융시장 전체의 AI 도입 효과나 동일 모델 공유 자체의 독립적인 인과효과를 식별하지 않는다.
  2. 업무 대응. 3단계의 상위 구조는 문헌에 근거하지만 LLM 호출 경계는 연구 구현이다. ③은 피드백 기능의 사전 점검이며, 실제 체결·거래비용·시간 경과·사후 성과평가를 재현하지 않는다. 결론은 “이 설계의 점검 단계”로 한정한다.
  3. 자산 수준과 분류 누락. 12산업은 분류 가능한 주식 부문의 대리 과제다. 해외·비상장·비공개 보유에 SIC가 없을 수 있다. 분류되지 않은 자산은 고정하고 원래 비중·분류율을 보존한다. 90% 자료 품질 기준 자체도 연구 선택이며 전체 펀드의 실제 위험을 계산하는 것은 아니다.
  4. 가상상황의 현실성. 정규성·조건부 독립·공통 위험 공분산·상대 정밀도는 모형 가정이다. 실제 보유내역과 역사 자료를 사용해도 사건의 인과관계, 꼬리위험, 내부 리서치를 모두 재현하지 않는다. Σ는 외생 위험척도이며 기대수익 불확실성을 포함한 완전한 사후예측분산이 아니다.
  5. 기준배분의 의미. 수학적 정답은 명시한 목적·정보·제약 안의 해다. 실제 펀드의 공식 최적 전략이나 미래 실현수익의 정답을 의미하지 않는다. 다중 최적해에서 특정 해와의 거리만으로 오류를 선언하지 않는다.
  6. 처치 해석. R0 차이에는 정보의 부재가 포함된다. R1–R3는 최초 제공 시점과 그 이후의 누적 노출을 함께 바꾸는 업무 정책 비교다. 순수한 위치 효과와 누적 노출 효과를 각각 분리했다고 주장하지 않는다.
  7. 검색과 전체 문맥. 고정 질의·BM25의 결과를 모든 검색 방식에 일반화하지 않는다. C-context의 길이·비용은 검색 조건과 다르며, 원문이 짧아 두 입력이 같아지는 사례도 공개한다.
  8. 지표 해석. G 감소만으로 좋은 다양성이 회복되었다고 할 수 없다. 과도한 차이, 기준배분 방향, regret, 위반·실패율을 함께 본다. 유효 출력만의 품질 비교는 성공 사례 구성 차이의 영향을 받는다.
  9. 표본과 통계. 60상황은 자원과 민감도 분석을 고려한 권고 규모다. 정규 대응차이·완전 자료 가정의 d≈0.46은 실제 검정력 보장이 아니다. 무효 출력으로 유효 상황 수가 줄 수 있다. 펀드 쌍·반복을 독립 표본으로 세지 않으며 비유의성으로 동등성·비악화를 선언하지 않는다.
  10. 자동 채점 범위. 숫자·출처·제약의 일치는 전체 금융 추론의 정당성이나 모델 내부 논리를 측정하지 않는다. 검토 표본에서 오류가 없더라도 전체 추출이 완벽하다는 뜻은 아니다.
  11. 선택과 재현. 네 펀드는 목적표집으로, 전체 운용사 모집단의 대표 표본이 아니다. 토글의 확정은 설계 결정이며 보유표 추출·산업 매핑 감사·코드 실행 완료가 아니다. 자료 검증, 계정 사용 가능성, 파일럿 토큰 실측, 검토자·예산·일정의 운영 확인은 남아 있다. 변경은 AI 본실험 전에 기록한다.
  12. 모델·비용·최적성. GPT-4.1 mini는 비용·버전 고정·도구 지원에 근거해 선택했다. 최신 또는 가장 우수한 모델의 결과로 일반화하지 않는다. 제시한 달러 비용은 가정에 따른 예시이며 토큰 길이·도구 왕복·실패 재시도에 따라 달라진다. 검색·생성 수치를 성능 최적값으로 검증한 상태는 아니다.
  13. 자료 빈티지. 현재 취득하는 French 수익률 자료의 과거 구간을 생성기 보정에 사용한다. 개별 공시 공개일은 T₀로 통제하지만 모든 데이터가 과거 시점 빈티지인 백테스트라고 주장하지 않는다. 실제 문서 C 검증은 소수 시점의 구현 확인이다.
  14. 결과 미실행. 본 문서의 표본 수·호출 수·설정은 설계값이다. 이미 효과가 확인되었다는 결과나 실행 완료를 의미하지 않는다.
