# PortBench T5 공개자료 이전: 계산 준비 결과

이 폴더는 **실험 대상을 선택하기 전의 계산 시제품**이다. LLM 응답이나 실제 거래 결과를 생성하지 않았다. PortBench 원본의 여러 자산군 자료를 복제한 결과가 아니라, 공개 FF12 산업 자료에 T5 과제를 옮겨 계산한 결과다.

실행:

```powershell
python research/compute_portbench_reference.py --self-check
python research/compute_portbench_reference.py
```

입력은 `data/french/ff12_daily.json`이며, 원자료 URL·다운로드 시각·파일 해시는 `data/french/manifest.json`에 기록되어 있다. NumPy와 SciPy가 필요하며, 이 코드는 네트워크나 모델 API를 호출하지 않는다.

|파일|내용|
|---|---|
|`ff12_t5_references.json`|모든 월말의 60개 입력 날짜, 연율화 평균·공분산, 기준 비중, 수치 검증, 입력·코드 해시|
|`weights.csv`|132개 월말의 기준 비중과 상태를 비교할 표|
|`summary.json`|검증 개수, 잔차, fallback과 모든 초과수익이 비양수인 날짜|

## 직접 차용과 변경 사항

근거는 [PortBench v6](https://arxiv.org/html/2605.27887v6)의 Appendix C.1 T5이다. 목표는 연간 무위험수익률 4%를 뺀 Sharpe 최대화이며, 비중은 음수가 없고 합계가 1이다. 추정 창은 일간 수익률 60개다. 수치 최적화 실패 시 균등비중을 사용하는 정책과 T5 cosine 채점도 출처에 명시되어 있다. 균등비중 fallback은 최적해로 표시하지 않는다.

연율화 계수 252는 같은 논문 B.2의 관례를 적용했다. 평균은 산술 표본평균, 공분산은 `ddof=1` 표본공분산으로 구현한다. 이 구체적 수치 구현과 아래 전역해 계산법은 별도 표기한 구현 선택이며, 원저자의 코드를 재현했다고 주장하지 않는다.

공개 FF12의 배당 포함 가치가중 일간 수익률을 사용하고, 2015년 1월부터 2025년 12월까지 각 월 마지막 관측일을 선택한 것은 **새로운 자료·일정 이전**이다. 132개는 달력으로 계산한 준비 사례 수이며 독립 표본 수나 필요한 실험 규모의 문헌 권고가 아니다. 창이 겹치므로 사례들이 통계적으로 독립적이라고 가정할 수 없다. 원자료에는 이후 개정된 과거 수익률이 포함될 수 있어 엄밀한 당시 배포판을 사용한 투자 백테스트로도 설명하지 않는다.

20% 재배분 한도, 15bps 비용 포함 목적, 현재 보유의 분산 이하 제약, 가상 개별 신호는 이 시제품에서 사용하지 않는다. 이들은 T5 원형의 조건이 아니다.

## 수치 검증

`a = mu - 0.04`의 양수 원소가 있으면 양의 Sharpe를 달성할 수 있다. 이 경우 `a'y=1, y>=0` 아래 `y'Sigma y`를 최소화한 뒤 `w=y/sum(y)`로 복원하면 같은 목표의 전역해를 얻는다. 수치 크기를 조정한 동등한 문제를 SLSQP로 풀고, 발견한 활성집합을 다듬은 다음 primal·dual 경계, KKT 잔차와 비중 제약을 검산한다. 부동소수점 검증을 정확 산술의 형식적 증명과 혼동하지 않는다.

모든 `a_i<=0`이면 `a_i/sqrt(Sigma_ii)`가 가장 큰 한 자산에 배분하는 해가 전역 최적이다. 공분산이 만드는 노름의 삼각부등식으로 혼합 포트폴리오가 이 값을 넘을 수 없음을 확인할 수 있다. 이 분기는 일반적인 양수 초과수익 변환을 잘못 적용하지 않기 위해 별도로 처리한다.

현재 실행에서는 132개 모두 양의 정부호 공분산과 유효 비중을 확인했다. 양의 초과수익 분기 126개, 비양수 분기 6개이며 fallback은 없다. 실행별 상세 잔차와 해시는 `summary.json`을 따른다.

## 채점 준비

`score_t5_response`는 명시적인 JSON 비중 벡터와 기준 벡터의 cosine을 계산한다. 누락·파싱 불가·0벡터는 0으로 기록한다. 원출력 비중을 수리하거나 정규화하지 않고, 제약 준수는 별도 보고한다. 논문에는 파싱되지만 음수인 비중 등 모든 잘못된 응답의 추가 처리가 자세히 정의되어 있지 않다. 따라서 함수는 raw cosine을 보존하며, 실제 LLM 실험 전에 이 미정 처리 규칙을 동결해야 한다. 현재 폴더의 비중은 전부 계산기의 기준 답이며 AI가 제출한 답이 아니다.
