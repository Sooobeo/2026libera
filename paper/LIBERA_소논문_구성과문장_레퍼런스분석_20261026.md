## 0. 집필 방향과 이 문서 사용법

**서론·논의의 큰 흐름은 Doshi와 Hauser, 금융 실험의 설계 설명은 Hornuf 등, 평가 개념의 정의는 Matton 등, 결과 이후의 재해석은 Bommasani 등과 Laban 등을 우선 참고하는 조합을 권한다.** 한 논문의 목차 전체를 옮기기보다, 현재 텀페이퍼의 각 부분에 필요한 문단 기능을 골라 적용한다.

현재 연구의 성격은 **다섯 조건의 탐색적 산업배분 사례 분석과 그 관찰에 근거한 업무 설계 제안**이다. 따라서 글의 중심 논리는 다음과 같이 잡는 것이 적합하다.

> 여러 기관이 검색·요약·평가에서 공통 AI를 사용하면 판단 방식도 공유할 수 있다 → 기관별로 필요한 차이가 약해질 가능성을 문제로 제기한다 → 이 넓은 문제 중 서로 다른 공개 근거가 최종 선택까지 이어지는 연결을 관찰한다 → 자료 요약과 실제 비중이 어긋나는 지점을 분석한다 → 필요한 근거 반응과 판단 품질을 함께 보존할 절차 및 후속 검증을 제안한다.

**문제 제기를 보존하는 편집 원칙 — 2026-10-26 추가.** 초기 [제안서](../plan/문규리%20제안서%20상세_최종.html)의 핵심은 기관들이 같은 투자 규칙을 공식 채택하지 않아도 개별 업무의 AI 산출물을 통해 공통된 판단 방식을 공유할 수 있다는 발생경로다. ‘자료를 정확히 요약하는가’로 곧바로 시작하면 이 문제를 일반적인 오류 점검으로 축소하게 된다. 서론은 발생경로와 금융에서 중요한 이유를 먼저 제시하고, 그다음 현재 실험이 관찰하는 작은 연결로 범위를 좁힌다.

기관별로 **필요한 차이**와 단순한 **출력 차이**도 구분한다. 타당한 공통 근거에 따른 수렴은 합리적일 수 있다. 현재의 다섯 공개전망 조건에는 실제 목표·보유자산·제약별 정답 배분이 없어 과잉수렴을 직접 판정할 수 없지만, 기관 자료를 추가한 뒤 설명과 비중의 연결을 확인해야 하는 이유는 분명하게 서술할 수 있다. 결과와 대응의 각 장, 결론은 이 연결을 회수해야 한다. 현재의 자료 직접 제공을 검색 RAG 구현이나 RAG의 완화효과 검증으로 바꾸어 쓰지 않는다.

이 문서에서 **‘원문 관찰’은 실제로 확인한 논문의 구성**, **‘LIBERA 적용’은 그 구성에서 도출한 집필 제안**을 뜻한다. 아래 한국어 예문은 이 원고를 위해 새로 작성한 문장으로, 참고 논문의 원문이나 번역문이 아니다. 문장 틀을 참고했더라도 해당 논문의 주장·개념·방법을 사용한 곳에는 별도로 인용한다.

추천 읽기 순서는 다음과 같다.

1. 빠르게 방향을 잡으려면 **1절의 레퍼런스 표 → 3절의 서론 설계 → 4절의 목차별 가이드**를 읽는다.
2. 실제 초고를 쓸 때는 **5절의 문장 틀과 6절의 수정 예시**를 함께 사용한다.
3. 제출 전에는 **7절의 주장 범위 점검표와 8절의 출처·확인 범위**를 확인한다.

## 2. 원문에서 확인한 구성 방식

### R1. Hornuf 등: 공통 투자 과제에서 정보 조건을 비교하는 방식

**원문 관찰.** 투자 의사결정이라는 실무 문제에서 출발하여 추가 정보가 어떤 차이를 만드는지로 질문을 좁힌다. 서론에서는 기존 연구와의 차이, 비교 설계, 주요 결과와 기여를 연결한다. 실제 절은 Introduction → Background → Experimental design → Construction of key variables → Results → Conclusion 순서이며, 별도 Discussion 절 없이 결론에서 함의와 한계를 회수한다. 확인 위치는 서론 인쇄 pp.2–4, 결과 pp.18–25, 결론 pp.26–27이다. 표지 포함 PDF 쪽수는 각각 4–6, 20–27, 28–29쪽이다. [CESifo 원문](https://www.ifo.de/DocDL/cesifo1_wp11862.pdf)

**LIBERA 적용.** 4장에서는 공통 과제와 기관 자료 제공 조건을 먼저 설명하고, 구현 설정은 뒤에 둔다. 3장에서는 각 비교가 답하는 질문을 함께 적는다. 이 논문의 성과 평가나 인과 추정의 표현은 현재 다섯 사례에 이전하지 않는다.

**빌릴 기능:** 실무 문제 → 추가 정보에 관한 질문 → 비교 조건 → 관측 결과 → 연구 기여.

### R2. Doshi와 Hauser: 큰 문제를 작은 과제로 좁히고 평가축을 나누는 방식

**원문 관찰.** 서론 pp.1–2는 창의성의 중요성·AI 관련 공백 → 짧은 이야기 쓰기라는 과제 선택 → 새로움과 유용성의 정의 → 개선과 제약이라는 두 가능성 → 실험 개요로 전개된다. 본문 순서는 Introduction → Results → Discussion → Materials and Methods이다. Results pp.2–5는 조건 비교, 부가 분석, 개인 차이, 산출물 유사성을 구분한다. Discussion pp.5–7은 주요 관측을 회수한 뒤 설계의 제약과 후속 질문을 논의한다. [게재본·UCL 저장소](https://discovery.ucl.ac.uk/id/eprint/10195027/)

**LIBERA 적용.** 사회·경제 전체의 동질화 문제를 기관 공개자료의 해석 과제로 좁히는 서론에 적합하다. 배분 간 거리와 근거 충실성도 별도 평가축으로 설명한다. 다만 이 저널의 ‘방법을 뒤에 두는 순서’까지 따라갈 필요는 없다. 현재 목차는 설계·평가를 결과 앞에 유지한다.

**빌릴 기능:** 큰 질문 → 관찰 가능한 작은 과제 → 구분할 개념 → 경쟁 가능성 → 연구 개요.

### R3. Matton 등: 개념 정의와 측정 절차를 나누는 방식

**원문 관찰.** 서론 pp.1–3은 설득력 있는 설명과 실제 근거 사용이 일치하는지 질문하고, 사례·평가 공백·새 정의·검증 방법을 연결한다. 실제 구성은 Introduction → Defining Causal Concept Faithfulness → Estimating Causal Concept Faithfulness → Experiments → Related Work → Limitations → Conclusion이다. 정의 §2와 추정 §3을 분리하고, 실험에서는 전체 평가와 세부 사례를 함께 살핀다. 한계 §6은 표본·보조 모델·프롬프트·개념 간 관계·모델 범위를 구체적으로 다룬다. [ICLR 공식 원문](https://proceedings.iclr.cc/paper_files/paper/2025/file/b5ec50eb177908f21f78ed0d76ed525c-Paper-Conference.pdf)

**LIBERA 적용.** 5.2에서 ‘충실한 반영’의 판정 대상을 먼저 정의한 뒤 증거 대조 절차를 설명한다. 자료 요약, 선택 이유, 실제 비중은 서로 다른 확인 대상이다. 이 논문의 인과적 충실성 검사를 현재 연구가 이미 수행했다고 쓰면 안 된다.

**빌릴 기능:** 평가하려는 성질 → 조작적 정의 → 관측·계산 절차 → 사례 → 측정 한계.

### R4. Laban 등: 비교 설계·결과·대응·한계를 구분하는 방식

**원문 관찰.** §1은 실제 사용과 기존 평가 방식의 간극에서 출발하여 정보 전달을 달리하는 비교와 기여를 소개한다. 본문은 Background and Related Work → Simulating Underspecified, Multi-Turn Conversation → Task and Metric Selection → Simulation Scale and Parameters → Results → Implications → Conclusion → Limitations 순서다. §6은 전체 결과, 지표별 분해, 추가 검증으로 이어진다. §7은 대응책과 그 실험 결과를 다루고 §9는 시뮬레이션과 실제 대화의 차이를 밝힌다. [arXiv v1 원문](https://arxiv.org/html/2505.06120v1)

**LIBERA 적용.** 6장은 관측, 7장은 해석, 8장은 대응 설계, 9장은 검증 범위로 역할을 나눈다. 특히 이 논문에서 시험한 대응책과 달리 LIBERA의 새 대응 설계는 미검증이라는 상태를 표시한다. E/L 비교를 순수한 기억·앵커링 효과로 부르지 않는다.

**빌릴 기능:** 평가 관행의 간극 → 비교 설계 → 결과 분해 → 대응 → 남은 제약.

### R5. Bommasani 등: 예상과 다른 결과를 포함해 설명의 범위를 수정하는 방식

**원문 관찰.** §1은 공유 관행의 효용과 위험을 제기하고, 채용 사례를 거쳐 측정할 대상을 설명한다. 이어 Outcome Homogenization in Resume Screening → Formalizing Outcome Homogenization → Data-Sharing Experiments → Model-Sharing Experiments → Societal Considerations and Challenges → Limitations and Conclusion으로 전개된다. §5.1–5.3은 예상과 어긋나는 결과, 가능한 설명, 이를 지지하는 증거의 범위를 함께 논의한다. 직관적 사례에서 형식적 지표로 이동하는 구성이 특징이다. [NeurIPS 공식 원문](https://proceedings.neurips.cc/paper_files/paper/2022/file/17a234c91f746d9625a75cf8a8731ee2-Paper-Conference.pdf)

**LIBERA 적용.** 7장에서 ‘공통 AI이므로 결과가 같아질 것’이라는 예상과 실제 배분 차이를 함께 검토한다. 같은 결과와 같은 오류, 다른 결과와 독립적 판단을 각각 구분한다. 채용에서 정의한 피해나 지표를 금융배분의 사회적 피해와 동일시하지 않는다.

**빌릴 기능:** 예상 → 어긋나는 관측 → 설명 수정 → 대안 설명 → 적용 조건.

### R6. Quek 등: 입력·처리·산출을 독자가 따라가게 설명하는 방식

**원문 관찰.** 산업배분 시스템을 Design Process에서 개괄하고 Methodology에서 구현과 비교 방법을 구체화한다. 거시 자료와 산업 관점이 배분으로 이어지는 흐름은 4장 작성에 참고할 수 있다. 다만 v5에서는 §3·Table 1의 2019년 상반기 백테스트 기간과 §7의 기간 서술이 일치하지 않는 부분이 있으며, §6의 강한 성과 표현을 통계적 유의성의 문체로 모방해서는 안 된다. [arXiv v5 원문](https://arxiv.org/html/2503.09647v5)

**LIBERA 적용.** 자료 묶음 → D0 → 계산 피드백 → F0를 먼저 설명하고 세부 설정으로 이동한다. 현재 과제는 거래성과 백테스트가 아니므로 원 논문의 수익성 중심 결론과 구분한다. 본문이 밝힌 게재 맥락은 ICLR 금융 AI 워크숍이며 ICLR 본회의 논문으로 표기하지 않는다.

**빌릴 기능:** 시스템 개요 → 단계별 입력·처리·산출 → 비교 방법.

### R7. Hansen과 Lee: 금융 전체의 문제와 실험으로 답할 수 있는 범위를 연결하는 방식

**원문 관찰.** 서론 인쇄 pp.2–6은 금융 불안정 문제 → AI 도입 → 안정화·불안정화의 경쟁 가능성 → 군집행동의 정의 → 기존 인간 실험을 활용한 비교 → 결과와 변형 실험으로 이어진다. 본문은 문헌, 군집행동과 금융안정, 실험 설계·환경, 결과, 실험의 확장·변형, 금융안정에 관한 논의, 결론 순서다. 결과 pp.17–23과 변형 실험 pp.23–27 뒤에 논의 pp.27–28을 배치하여 관측의 조건을 점검한 후 함의로 이동한다. [연준 공식 논문 페이지](https://www.federalreserve.gov/econres/feds/financial-stability-implications-of-generative-ai-taming-the-animal-spirits.htm), [공식 PDF](https://www.federalreserve.gov/econres/feds/files/2025090pap.pdf)

**LIBERA 적용.** 7.4는 기존 금융 실험과 본고의 차이를 밝히는 문단으로 쓴다. 투자 주체 간 상호작용이나 시장 가격을 관측한 연구의 결론을, 공개 문서 조건 다섯 개의 배분 차이에 직접 적용하지 않는다.

**빌릴 기능:** 큰 금융 문제 → 관측할 의사결정 → 실험 범위 → 그 범위 안의 함의.

### R8. 국내 보조 후보: 초록·목차까지만 확인한 논문

이재욱·도영훈·이민혁의 「ChatGPT와 CoT 프롬프팅을 활용한 ETF 자산배분 전략」은 *경영정보학연구* 27(3), 335–354에 수록되었다. 공개 목차는 **서론 → 이론적 배경 → 방법론 → 결과 분석 → 결론**이다. 이론적 배경에서는 AI 자산운용·텍스트 데이터·LLM 투자전략을 구분하고, 방법론은 자료 수집·전처리, GPT 프롬프팅·분석, 투자전략 실증으로 나뉜다. [논문 서지](https://doi.org/10.14329/isr.2025.27.3.335), [초록·목차 제공 페이지](https://www.earticle.net/Article/A471857)

**활용 범위.** 국내 경영·정보 분야의 목차와 용어를 확인하는 보조 후보로 남긴다. 본문은 확보하지 못했으므로 서론의 문단 배치, 실제 문장 길이·문체, 결과의 논증 방식은 분석하지 않았다. 위의 목차 관찰만으로 본문 문장이 좋다고 추천하는 것은 아니다.

## 3. 서론은 어떻게 구성할 것인가

### 3.1 현재 서론에서 보강할 지점

v5.1 서론은 대체로 **AI 활용 문제 → 동질화 문헌 → 학술제 맥락과 범위 → ‘기관’의 정의**로 이어진다. 연구 범위는 분명하지만 마지막에 남아야 할 **연구 공백과 본고의 기여**가 상대적으로 약하다. 서론 끝을 용어 제한으로 마무리하기보다, 왜 이 분석을 해야 하는지와 무엇을 새로 보여주는지로 끝내는 편이 좋다.

학술제 주제 소개는 간단히 두고, 그 자리에 다음 질문을 전면화한다.

> 서로 다른 배분이 나왔다는 사실만으로, 기관의 근거가 실제 선택에 충실하게 반영되었다고 판단할 수 있는가?

이는 검토한 문헌과 본 연구의 대상·설계를 비교하여 설정한 질문이다. 관련 연구 전체가 이 문제를 한 번도 다루지 않았다고 주장할 근거는 확보하지 않았다.

### 3.2 권장 서론: 다섯 문단의 기능

다음은 R1·R2·R3·R5에서 참고한 전개 기능을 현재 목차에 맞춰 재구성한 집필안이다. 모든 소논문의 필수 형식이나 문헌이 정한 규칙은 아니다.

| 문단 | 문단의 임무 | 문장 순서 | 마지막에 독자가 알아야 할 것 |
|---|---|---|---|
| 1 | 연구할 현상을 구체화 | 공통 AI의 투자업무 활용 → 서로 다른 기관 근거 → 근거가 선택까지 이어지는지라는 문제 | ‘AI 일반론’에서 다룰 실제 문제가 정해짐 |
| 2 | 기존 논의의 두 축 제시 | 공유 모델·다양성 연구 → 금융 정보 제공 실험 → 이들이 제공하는 관점 | 관련 분야와 연결되지만 과제가 같지는 않음 |
| 3 | 연구 공백 도출 | 배분 차이로 알 수 있는 것 → 차이만으로 알 수 없는 것 → 요약·이유·선택 연결의 필요 | 왜 기존 비교에 다른 분석축을 더하는지 |
| 4 | 본 연구의 대상·방법·질문 소개 | 공개 전망 두 자료원 → 다섯 조건 → 자료 의미·설명·비중 대조 → 세 연구질문 요약 | 실제로 무엇을 관찰하는 연구인지 |
| 5 | 기여와 주장 범위 확정 | 연결이 어긋나는 지점의 제시 → 원비중·파생값 구분 → 후속 대응 설계 → 탐색 사례의 한계 | 무엇을 더했고 어디까지 말할 수 있는지 |

### 3.3 문단별 한국어 문장 틀

**1문단: 현상과 의사결정 문제.**

> 생성형 AI를 투자 의사결정에 활용할 때에는 자료의 요약뿐 아니라 그 자료가 어떤 선택을 지지하는지 검토할 필요가 있다. 같은 모델을 사용하는 기관들도 서로 다른 전망과 판단 근거를 제공할 수 있다. 이때 기관 자료가 설명에 재현되는 것과 실제 배분의 이유로 사용되는 것은 구분하여 확인해야 한다.

이 문단의 주어는 ‘AI 기술’보다 ‘기관의 자료와 선택’에 둔다. AI의 역사, 성능 발전, 모든 산업의 변화까지 확장할 필요는 없다.

**2문단: 알려진 것과 문헌 간 연결.**

> 공유 모델과 산출물의 관계를 검토하려면 결과의 유사성과 개별 판단의 적절성을 나누어 볼 필요가 있다. 본고는 공통 알고리즘과 산출물 다양성을 다룬 논의, 금융배분에서 정보 조건을 비교한 실험, 설명 충실성을 평가하는 연구를 함께 검토한다. 이를 통해 기관 자료의 반영을 배분 차이와 근거 연결이라는 두 측면에서 살펴본다.

이것은 문헌을 연결하는 예문이다. 실제 초고에서는 2장의 문헌 검토를 바탕으로 관련 문장에 R1·R3·R5 등의 인용을 붙인다. 서론에 각 논문의 세부 실험을 모두 설명하지 않는다.

**3문단: 연구 공백.**

> 그러나 배분 간 차이만으로는 제공된 기관 근거가 최종 선택을 지지하는지 확인하기 어렵다. 자료 요약이 정확하더라도 선택 이유에 다른 전제가 추가되거나 설명과 비중이 어긋날 수 있기 때문이다. 따라서 기관 원문의 의미, 모델이 밝힌 이유, 실제 제출 비중을 연결하여 검토할 필요가 있다.

‘기존 연구가 부족하다’로 끝내지 말고, **무엇을 함께 대조해야 그 질문에 답할 수 있는지**까지 쓴다.

**4문단: 대상과 접근.**

> 이에 본 연구는 공통 생성형 AI에 Fidelity와 UBS의 공개 산업전망을 초기·후기 제공하거나 제공하지 않는 다섯 조건을 탐색적으로 분석한다. 동일한 시장 상황에서 각 조건의 자료 의미와 설명 및 배분의 대응을 검토한다. 분석은 기관 자료의 해석, 대조군과의 배분 차이, 제공 절차별 수정 양상이라는 세 질문을 중심으로 수행한다.

세 질문의 전문과 비교표는 3장에 둔다. 서론에서는 연구의 윤곽을 읽을 수 있을 정도로 요약한다.

**5문단: 기여와 범위.**

> 본 연구는 공개 자료의 재현과 근거에 충실한 선택이 분리되는 지점을 사례로 제시한다. 또한 원비중과 외부 계산으로 산출한 파생 배분을 구분하여, 사후 변환이 선택의 증감 해석에 미치는 영향을 살펴본다. 이러한 관찰을 바탕으로 근거와 선택을 연결하는 검토 절차를 제안하되, 그 개선 효과는 후속 검증의 과제로 남긴다. 본고에서 기관은 공개 전망을 제공한 자료 조건이며, 결과의 해석 범위도 실제 기관의 운용행동과 구분한다.

이 예문은 서론의 마지막을 ‘무엇을 수행하는가’와 ‘기여의 범위’로 정리하는 방식이다. 학교가 서론 말미의 장 안내를 요구하면 마지막에 한 문장으로 덧붙인다.

### 3.4 서론에서 본론으로의 연결

서론에서 제기한 ‘자료 → 설명 → 선택’이 2.3의 평가 관점, 3장의 연구질문, 5.2의 판정 절차, 6.4의 사례 분석에서 같은 뜻으로 사용되어야 한다. 용어가 장마다 달라지면 하나의 연구가 아니라 서로 다른 문제를 연달아 소개하는 글처럼 읽힐 수 있다.

## 4. 입력된 텀페이퍼 목차별 집필 설계

아래 번호와 제목은 v5.1의 목차를 따른다. 원고의 `2 1` 표기는 가독성을 위해 `2.1`로 표기하였다. 본문 원고와 실험 자료는 수정하지 않았다.

### 국문초록

**추천 구성:** 목적 1문장 → 대상·비교·방법 2문장 → 핵심 관측 2문장 → 기여·대응 1문장 → 한계 1문장.

R2의 초록에서 참고할 것은 연구 전체의 논리 순서다. 초록 안에 모든 문헌과 대응 장치의 세부 항목을 나열하기보다, 관측한 것과 제안한 것을 독립적으로 이해할 수 있게 쓴다. 현재 초록에서는 외부 산업 사례의 이름을 줄이면 연구 결과와 기여가 더 잘 드러난다.

**문장 틀:** “본 연구는 [대상]에서 [질문]을 살펴본 탐색적 사례연구이다. [조건과 방법]으로 분석한 결과, [관측 1]과 [관측 2]가 확인되었다. 이를 바탕으로 [제안]을 제시하며, [남은 검증]을 후속 과제로 둔다.”

### 1 서론

3절의 다섯 문단 구성을 적용한다. 끝에서 ① 분석하는 연결, ② 원비중·파생값의 구분, ③ 대응 설계의 제안이라는 기여를 회수한다. ‘AI가 중요한 시대’라는 배경 설명이 연구 질문보다 길어지지 않도록 한다.

### 2 선행연구와 연구의 위치

**주 레퍼런스:** R1·R3·R5. **문단 기본형:** 공통 논점 → 관련 연구 → 차이와 적용 범위 → 본고의 선택.

| 소절 | 권장 문단 순서 | 소절을 마치는 문장 기능 |
|---|---|---|
| 2.1 공통 AI와 산출물 다양성 | 개별 품질·집단 다양성 구분 → 공유 모델 연구 → 현재 금융 과제로 옮길 수 있는 관점 | “이에 본고는 배분 간 거리와 근거 반영의 적절성을 별도로 평가한다.” |
| 2.2 금융 배분과 정보 제공 절차 | 금융 과제의 정보 조건 → 산업배분 과제 → 대화·정보 전달 절차 → 현재 E/L 비교 | “본고는 자료 제공 절차를 비교하되 함께 달라지는 초안과 이력을 해석에 반영한다.” |
| 2.3 근거와 선택을 연결하는 평가 | 설명 충실성의 질문 → 자료·설명·행동의 구분 → 현재의 대조 단위 | “본고의 관찰 단위는 자료 의미, 모델의 이유, 실제 비중 사이의 대응이다.” |

저자별 소개를 연달아 붙이는 데서 끝내지 않는다. 각 소절 마지막에서 **그 문헌들을 검토한 결과 본 연구가 어떤 평가 관점을 택하는지**를 명시한다. ‘최초’라는 표현 대신 대상·비교·관찰 단위에서의 차이를 구체적으로 쓴다.

### 3 연구질문과 비교 논리

**주 레퍼런스:** R1의 정보 조건 비교, R4의 비교 설계 설명. 질문과 증거를 한 묶음으로 제시한다.

| 질문 | 필요한 비교·증거 | 답할 수 있는 범위 |
|---|---|---|
| RQ1 기관 전망을 설명에 정확히 반영하는가 | 기관 원문·제공 자료 ↔ 모델의 자료 요약·이유·비중 | 어느 연결에서 보존·오류·미해결이 나타나는지 |
| RQ2 기관 자료 조건의 최종안은 C와 어떻게 다른가 | 각 기관 조건의 F0 파생 배분 ↔ C의 F0 파생 배분 | 배분 차이의 크기와 양상 |
| RQ3 초기·후기 제공에서 수정 양상이 어떻게 다른가 | 같은 기관의 E/L, 각 조건의 D0/F0 및 설명 | 절차에 따라 관측된 수정 양상 |

**권장 문장:** “RQ2에는 기관 자료 조건과 C의 최종 파생 배분을 대조하여 답한다. 배분 거리는 산출물의 차이를 나타내며, 그 차이의 원인이나 근거 충실성을 직접 측정하는 값은 아니다.”

### 4 자료와 실험설계

**주 레퍼런스:** R1, R6. **장 전체 순서:** 과제 → 자료 → 공통 입력 → 조건·실행 흐름 → 재현 정보. 독자가 이해해야 할 연구 선택을 먼저 쓰고 프로그램 설정은 뒤에 둔다.

| 소절 | 문단·문장 순서 | 현재 자료를 활용할 지점 |
|---|---|---|
| 4.1 공통 투자 과제와 산업 범위 | 기준일·판단기간 → 투자 대상 → 제약 → 그 가정의 의미 | 미국 11개 GICS 섹터, ETF 대용, 새 자금의 가상 배분 |
| 4.2 기관별 공개 전망 자료 | 문서·기준시점 → 추출 항목 → 기관별 용어 차이 → 미제공 정보 처리 | Fidelity Q2·UBS June, 등급·이유·범위의 보존 |
| 4.3 공통 시장 상황과 시점 통제 | 공통 입력 → 자료의 기간·발표일 → 통계 계산 → 공통 기준 비중 → 자료 버전 한계 | 판단 기준일·60일 관측창·10월 수집일을 구분 |
| 4.4 다섯 조건과 두 단계의 실행 | E/L/C 조건표 → D0·피드백·F0 → C의 역할 → 완료·중단 기록 | 다섯 최종안, 열 개 완료 단계, 열한 번의 실제 생성 요청 |
| 4.5 모델과 실행 이력 | 모델·환경 → 설정표 → 중단·재개 → 분석 변경 | 소형 양자화 모델의 CPU 실행, 운영 이력, 사후 변경 |

**절차 문장 틀:** “모든 조건에 [공통 입력]을 제공하였다. E에는 [시점]부터 기관 자료를 제공하였고, L에는 [시점]에 처음 제공하였다. 이어 [다음 단계]를 수행하여 [산출물]을 확보하였다.”

**편집 포인트:** 현재 4.3에서 공통 자료의 구성과 임의 변환계수를 넣지 않았다는 설명이 반복된다. 한 번은 입력의 정의로, 한 번은 해석 범위로 정리하면 된다. 실제 수집일과 가상 판단 기준일은 같은 날짜처럼 합치지 않는다.

### 5 평가방법

**주 레퍼런스:** R3의 ‘정의와 추정’ 구분, R5의 ‘직관과 지표’ 연결. **장 전체 순서:** 어떤 성질을 보려는가 → 무엇을 대조하는가 → 어떻게 계산·판정하는가 → 어디까지 해석하는가.

| 소절 | 먼저 정의할 것 | 뒤이어 설명할 절차·해석 |
|---|---|---|
| 5.1 원응답 진단과 파생 배분의 구분 | 모델이 제출한 원비중과 외부 계산값 | 변환 적용 조건 → 비례 조정·잔여 배정 → 합계 100%의 의미 |
| 5.2 자료 충실성과 근거에서 배분으로의 연결 | 자료 의미, 모델의 이유, 실제 선택 | 원문 대조 → 채택·조정·비채택 확인 → 판정 범주·미해결 보존 |
| 5.3 수치 주장과 위험의 정의 | 수치의 단위·기간·대상, 과거 변동성 | 입력과 출력 대조 → 인용 존재와 내용 지지의 구분 |
| 5.4 배분 거리와 비교 단위 | 두 배분 사이의 TV 거리 | 직관 예시 → 계산식 → 비교쌍 → 독립 단위와 해석 제한 |
| 5.5 의미 검토와 보고의 한계 | AI 보조 검토와 부분 가림 검토의 역할 | 증거 위치 기록 → 분류 불일치 보존 → 종합점수·오류율 보고 범위 |

**정의 문장 예시:** “본고에서 자료 충실성은 기관 문서의 평가 방향·이유·적용 범위를 보존했는지에 관한 판단이다. 이어 설명이 밝힌 비교와 실제 제출 비중이 일치하는지를 별도로 대조한다.”

**지표 설명 예시:** “TV 거리는 두 파생 배분에서 서로 다르게 배치된 비중의 크기를 요약한다. 비중을 0~1로 나타낼 때 두 벡터의 산업별 절대 차이를 합한 뒤 2로 나누고, 보고값에는 100을 곱한다. 이 값이 크다는 사실은 근거를 더 충실하게 반영했다는 뜻이 아니다.”

R3를 참고했다는 이유로 ‘인과적 근거 사용을 측정했다’고 쓰지 않는다. 현재 수행한 것은 **문서·명시된 설명·숫자의 대응 검사**이며, 근거 개입 검사는 8~9장의 후속 제안이다.

### 6 실험 결과

**주 레퍼런스:** R2·R4. **결과 문단 기본형:** 핵심 관찰 → 표·사례 위치 → 중요한 비교 → 해석 범위. 표의 모든 숫자를 본문에서 다시 읽어 주지 않는다.

| 소절 | 본문에서 강조할 내용 | 권장 마무리 |
|---|---|---|
| 6.1 완료 범위와 합계 오류 | 최종안 5개·55개 산업행, 최종 원합계의 오류 | “파생 합계 100%는 외부 계산 결과이다.” |
| 6.2 다섯 조건의 최종 산업배분 | 정보기술이 공통 최대라는 점과 대표적인 차이 | “이 차이의 근거는 설명과 원문을 추가 대조하여 판단한다.” |
| 6.3 기관 자료 및 제공 절차별 배분 차이 | 기관 간·E/L·C·D0/F0 비교를 구분 | “거리의 차이만으로 제공 절차의 우열을 판단할 수 없다.” |
| 6.4 자료 요약 이후에 나타난 근거와 수치의 단절 | 산업행 요약 일치 이후의 수치·설명·귀속 오류 | “오류는 연결 단계별로 구분하여 보고한다.” |
| 6.5 연구질문에 대한 답 | RQ1→RQ2→RQ3 순서로 관측된 답 | 질문마다 답과 불확실성을 한 묶음으로 씀 |

**실제 관측을 사용한 문단 예시:**

> 기관 자료를 제공한 네 조건의 최종 파생 배분은 모두 C와 달랐으며, 거리는 4.76~12.98%였다(원고 표 7). 그러나 이 차이는 자료 반영의 충실성과 함께 해석해야 한다. 기관별 산업행의 등급과 자료 요약이 입력과 일치한 경우에도, 선택 이유와 종합 설명에서는 수치 및 비중 증감에 관한 오류가 확인되었다(원고 표 8).

이 예문에서 거리의 ‘%’는 원고가 정의한 거리 보고 단위를 따른다. 정보기술 비중의 38%→35% 변화는 **3%p 감소**라고 쓴다. 서로 다른 단위를 같은 ‘감소율’로 표현하지 않는다.

### 7 실험 결과의 재해석

**주 레퍼런스:** R5를 중심으로 R3·R4·R7. **문단 기본형:** 관측 1문장 → 가능한 의미 → 경쟁 설명 → 문헌과의 관계 → 설계 함의. 6장의 결과표를 다시 설명하는 장으로 만들지 않는다.

| 소절 | 해석에서 분리할 대상 | 권장 논증 |
|---|---|---|
| 7.1 정확한 자료 재현과 실제 판단의 분리 | 요약 정확성 / 선택의 근거 충실성 | 자료가 도달했다는 증거 → 그 뒤 연결이 끊기는 지점 → 추가 판단의 귀속 |
| 7.2 서로 다른 배분에 남는 공유 전제의 오류 | 배분의 다양성 / 판단 전제의 독립성 | 서로 다른 결과의 공유 오류 → 같은 D0의 이력 → 독립적 반복으로 볼 수 없는 이유 |
| 7.3 배분의 방향을 바꿀 수 있는 정규화 | 원비중의 증감 / 파생 비중의 증감 | 사후 진단임을 표시 → 분모 변화 설명 → 원래 선택과 외부 변환의 구분 |
| 7.4 최근 금융 연구가 제기하는 차별화의 조건 | 다른 금융 실험의 결과 / 현재 과제의 관측 | 행위자·정보·상호작용·성과척도 비교 → 현재 결과가 답할 수 있는 범위 |
| 7.5 설명을 평가하는 최근 연구의 시사점 | 설명의 언급 / 실제 근거 의존 / 행동 예측 | 현재 검사한 층 → 아직 검사하지 않은 층 → 후속 개입 검사의 필요 |

**정규화 사례를 해석하는 문단 예시:**

> Fidelity L에서 정보기술의 원비중은 38%에서 36%로 감소했으나, 파생 비중은 37.26%에서 40.91%로 증가하였다. 이 사후 진단은 정규화 분모의 변화가 증감 방향의 해석까지 바꿀 수 있음을 보여준다. 따라서 파생 비중의 증가를 모델이 해당 산업을 더 선호하게 되었다는 증거로 읽기는 어렵다. 후속 설계에서는 모델이 제안한 이동량과 합계 제약을 충족하기 위한 외부 조정을 함께 기록할 필요가 있다.

**공유 오류의 대안 설명 문장:** “세 조건에서 같은 수치 오류가 남았지만, 완료된 D0 원문도 동일하므로 이를 서로 독립된 세 번의 오류 발생으로 셀 수는 없다. 이 관측은 공유 전제의 잔존을 보여주며, 오류의 발생 원인을 분리하려면 독립적인 초기 생성이 필요하다.”

### 8 실험 해석에 근거한 대응 방향

**주 레퍼런스:** R4의 결과·대응 분리. 이 장의 구체적인 대응 내용은 기존 LIBERA 설계와 그 출처에서 가져온다. 문장 구조는 **실패 지점 → 설계 원리 → 적용 예 → 실패 가능 조건**으로 통일한다.

| 소절 | 출발할 관측·문제 | 제안의 중심 | 반드시 붙일 범위·예외 |
|---|---|---|---|
| 8.1 타 산업에서 가져올 구조와 적용 한계 | 금융 외부의 검증 구조가 필요한 이유 | 어떤 기능을 가져오는지 대응표로 제시 | 외부 산업의 성과가 현재 과제의 효과는 아님 |
| 8.2 공통 기본안에서 기회비용을 밝힌 변경안으로 | 정규화가 수정 방향을 바꿀 수 있음 | 유효 기본안 + 늘릴 곳·줄일 곳·기회비용 | 기본안이 틀리면 오류를 고정할 가능성 |
| 8.3 기관 근거를 따랐다는 설명을 행동으로 검증 | 근거 언급과 실제 선택의 괴리 | 의존 관계 선언 + 핵심 근거의 반사실 개입 + 의미 보존 개입에서의 안정성 | 다른 근거로 선택 유지가 합리적인 경우 |
| 8.4 기관 판단의 적용 권한과 확정된 선택 상태 | 기관 자료와 추가 운용판단의 혼합 | 자료의 주장·추가 판단·확정 선택의 구분 | 규칙이 잘못되거나 상태가 갱신되지 않는 경우 |
| 8.5 공유 오류를 판단의 의존 관계에 따라 복구 | 사실을 고쳐도 관련 판단이 남을 가능성 | 수정된 전제에 의존한 이유·배분의 재검토 | 올바른 판단까지 불필요하게 바꾸는 위험 |
| 8.6 공개자료 과제와 실제 기관 도입의 구분 | 공개자료로 관측할 수 있는 정보의 범위 | 현재 가능한 검토와 도입 시 필요한 정보 | 기관의 목적·위험한도·권한은 별도 필요 |

**제안 문단 예시:**

> 정규화 이후에 수정 방향이 달라지는 문제에 대응하기 위해, 합계 제약을 충족하는 공통 기본안에서 변경량을 제출하는 방식을 제안한다. 모델은 특정 산업의 증액과 함께 재원을 줄일 산업 및 그 기회비용을 설명한다. 계산기는 제안된 이동의 합계와 제약을 확인하고, 채택한 변경을 기본안에 적용한다. 이 방식이 판단의 충실성을 높이는지는 검증하지 않았으며, 기본안의 오류를 유지하는 부작용도 후속 비교에 포함해야 한다.

외부 산업 사례는 이름·성과를 길게 소개하기보다 **검증 대상 / 가져올 기능 / 적용할 위치 / 이전할 수 없는 조건**을 표로 모으는 편이 현재 소논문에 적합하다. 이는 분량을 정리하기 위한 편집 제안이며 외부 사례의 추가 사실 검증은 이 문서의 분석 범위에 포함하지 않았다.

### 9 한계와 후속 검증

**주 레퍼런스:** R2·R3·R4의 구체적인 한계 서술. **문단 기본형:** 제약 → 어떤 결론이 제한되는가 → 무엇을 추가로 비교할 것인가. 한계 항목과 후속 실험이 대응해야 한다.

| 소절 | 넣을 내용 | 권장 연결 |
|---|---|---|
| 9.1 관찰에서 설계 가설까지의 범위 | 한 모델·두 자료원·다섯 조건, 동일 초안·노출량·이력, 사후 분석 변경, 미검증 제안 | 각각이 일반화·원인 귀속·제안 효과에 미치는 영향 |
| 9.2 제안의 효과와 원인을 나누는 비교 | 새 자료, 동일 입력·자원, 전체 재작성과 변경안, 기능 제거 비교 | 개선이 어느 장치에서 왔는지 확인하는 비교 |
| 9.3 평가 단위와 채택 조건 | 독립 실행, 사람 검토, 오류·누락·보류·비용, 채택·수정 기준 | 어떤 결과이면 제안을 기각하거나 수정할지 |

**한계 문장 예시:** “각 조건에서 하나의 최종안만 확보하였으므로 관측된 거리의 모집단 분포를 추정할 수 없다. 후속 연구에서는 새 자료와 독립적인 초기 생성으로 각 조건을 반복하여 관측의 안정성을 확인해야 한다.”

**제안 검증 문장 예시:** “후속 비교에서는 변경안 방식과 전체 재작성 방식에 동일한 자료·기본안·계산 자원을 제공한다. 설명·비중의 불일치와 근거 없는 귀속, 적절한 보류, 처리 비용을 함께 비교하고, 오류가 줄더라도 정당한 변경을 과도하게 막는 경우에는 설계를 수정한다.”

### 10 결론

**추천 구성:** 첫 문단은 질문에 대한 답과 관측의 의미, 둘째 문단은 기여·제안·남은 검증으로 정리한다. 새로운 문헌, 새로운 성과 수치, 본문에서 설명하지 않은 대책은 결론에서 처음 꺼내지 않는다.

**문장 틀:** “본 사례에서는 [확인한 관측]이 나타났다. 이는 [평가상 구분]의 필요성을 보여준다. 본고는 이를 바탕으로 [설계 원리]를 제안하며, [남은 검증]을 전제로 [기여]를 제시한다.”

현재 원고의 마지막 메시지는 **‘기관 근거가 어떤 선택을 허용했는지 검토하는 절차’**로 모으면 좋다. 대응 장치의 이름을 모두 반복할 필요는 없다.

## 5. 문장구조와 문체: 부분마다 다른 동사를 쓴다

### 5.1 실제 원문 문장의 구조를 어떻게 가져올 것인가

아래 표는 원문 문장을 확인한 뒤 **절의 결합과 논증 기능만 추상화**한 것이다. 마지막 열은 새로 작성한 적용 예문이다. 원문의 영문 문장을 번역하거나 그 연구의 결과를 이 연구의 결과로 바꾸어 쓴 것이 아니다.

| 원문·확인 위치 | 문장의 추상 구조 | 문장에서 하는 일 | LIBERA 적용 예문 |
|---|---|---|---|
| [R2 게재본](https://discovery.ucl.ac.uk/id/eprint/10195027/), p.1 서론 첫 문단의 마지막 문장 | 기존 성과를 인정하는 양보절 + 남은 질문을 밝히는 주절 | 알려진 것에서 연구 공백으로 전환 | “배분 간 차이를 계산할 수는 있으나, 그 차이만으로 기관 근거가 사용되었는지 판단하기는 어렵다.” |
| R2, p.1 서론 두 번째 문단의 첫 문장 | 연구 목적을 나타내는 도입구 + 주어·능동 동사 + 한정한 대상 | 큰 질문을 관찰 가능한 과제로 축소 | “공통 AI의 기관 근거 반영을 살펴보기 위해, 분석 범위를 공개 산업전망에 대한 설명과 배분으로 한정한다.” |
| [R1 원문](https://www.ifo.de/DocDL/cesifo1_wp11862.pdf), 서론 인쇄 pp.3–4 기여 설명 문단 | 그럴듯한 직관을 인정하는 양보절 + 해석을 유보하는 주절 | 기대와 입증을 구분 | “기관 자료의 추가로 배분이 달라질 수 있으나, 차이가 크다는 사실만으로 근거에 충실한 선택을 확인할 수는 없다.” |
| [R3 원문](https://proceedings.iclr.cc/paper_files/paper/2025/file/b5ec50eb177908f21f78ed0d76ed525c-Paper-Conference.pdf), §1 p.1 성별 교환 사례 문단 | 조건절 + 기대되는 행동 / 다음 문장의 역접 + 실제 관찰 | 추상적 성질을 기대·관측의 비교로 전환 | “모델이 ‘초안보다 늘렸다’고 설명했다면, 최종 원비중이 초안보다 커야 한다. 그러나 UBS L의 정보기술 원비중은 38%에서 35%로 감소하였다.” |
| R3, §2 p.4 수식 앞 직관 설명 | 같은 조건 아래 높은 영향·높은 언급과 낮은 영향·낮은 언급을 대칭 배치 | 개념을 양방향 판정으로 구체화 | **후속 평가 기준 예시:** “핵심 근거를 바꾸었을 때 선언한 의존 조건에 맞게 반응하는지와, 의미를 보존한 변경에서는 선택이 안정적인지를 함께 확인한다.” |

R2 첫 구조는 서론의 공백 제시에, R1 구조는 결과를 과도하게 해석하지 않는 문장에 적합하다. R3의 조건·관측 구조는 5장의 판정 논리와 6장의 사례 대조에 참고할 수 있다. 다만 마지막 행의 반사실·의미 보존 비교는 **현재 완료한 평가가 아니라 후속 설계**이다.

### 5.2 주장 단계별 문장 틀

| 기능 | 권장 문장 틀 | 이 원고에서의 사용처 |
|---|---|---|
| 문제 제기 | “[업무]에서는 [성질 A]와 함께 [성질 B]를 검토할 필요가 있다.” | 서론 1문단 |
| 문헌 종합 | “[연구군]은 [공통 논점]을 다룬다. 본고는 그중 [관점]을 현재 과제에 적용한다.” | 2장 |
| 공백 특정 | “그러나 [현재 비교]만으로는 [남은 질문]을 확인하기 어렵다.” | 서론·2장 말미 |
| 범위 정의 | “본고에서 [용어]는 [관측 가능한 대상]을 의미한다.” | 4·5장 |
| 설계 이유 | “[대안적 해석]을 줄이기 위해 [공통 요소]를 동일하게 두었다.” | 4장 |
| 절차 기술 | “먼저 [처리]한 뒤, [다음 처리]를 수행하였다.” | 4·5장 |
| 결과 보고 | “[비교 단위]에서 [수치·패턴]이 관찰되었다(표 n).” | 6장 |
| 사례 대조 | “모델은 [설명]이라고 서술했으나 제출된 원비중은 [값]이었다.” | 6.4 |
| 해석 | “이 관측은 [구분·가능성]을 시사한다.” | 7장 |
| 대안 설명 | “[설명 A]와 함께 [설명 B]도 가능하며, 현재 설계에서는 이를 분리하기 어렵다.” | 7장 |
| 대응 제안 | “[실패]에 대응하기 위해 [절차]를 제안한다.” | 8장 |
| 효과 상태 | “이 절차의 개선 효과는 [후속 비교]에서 확인해야 한다.” | 8·9장 |
| 한계 연결 | “[제약]으로 인해 [특정 결론]은 도출하기 어렵다.” | 9장 |
| 기여 회수 | “본고의 기여는 [대상]에서 [확인한 관계·실패 지점]을 구체화한 데 있다.” | 서론 말미·결론 |

‘관찰하였다’는 자료에, ‘해석할 수 있다’는 의미에, ‘제안한다’는 설계에, ‘검증해야 한다’는 미래 작업에 대응시킨다. 같은 문단에서 이 단계가 바뀔 때 연결 문장을 둔다.

### 5.3 한 문장의 구조

1. **주어를 구체화한다.** ‘AI는’보다 ‘UBS L의 종합 설명은’, ‘Fidelity L의 원비중은’처럼 쓴다.
2. **비교 기준을 문장 안에 둔다.** ‘비중이 높다’ 대신 ‘공통 비교 기준보다 높다’ 또는 ‘D0보다 증가했다’고 쓴다.
3. **관측과 해석을 나눈다.** 첫 문장에 값·표·사례를 쓰고 다음 문장에서 그 의미를 설명한다.
4. **인과 접속어는 설계가 뒷받침할 때 쓴다.** 현재 E/L 관측에는 ‘~때문에’보다 ‘~와 함께 나타났다’, ‘~를 분리하기 어렵다’가 적합하다.
5. **핵심 명칭을 고정한다.** ‘원비중’, ‘파생 배분’, ‘기관 자료 조건’, ‘설명과 실제 비중의 대응’을 장마다 다른 말로 바꾸지 않는다.
6. **평가 대상을 생략하지 않는다.** ‘정확했다’ 대신 ‘산업행의 등급과 자료 요약이 입력과 일치했다’고 쓴다.

### 5.4 문단의 구조

일반적인 분석 문단은 **주제문 → 증거·설명 → 해석 → 다음 논점**으로 쓴다. 모든 문단을 네 문장으로 맞출 필요는 없지만, 한 문단 안에서 답하려는 질문은 하나로 유지한다.

예를 들어 7.2의 문단에서 공유 오류의 의미를 설명하다가 모델 설정과 타 산업 사례까지 들어가면 논점이 흩어진다. 설정은 4.5, 대응 사례는 8.1에 두고 필요한 연결만 남긴다.

| 문단 역할 | 첫 문장 | 마지막 문장 |
|---|---|---|
| 문헌 검토 | 공통 문제나 분석축을 제시 | 본고가 취할 관점을 확정 |
| 방법 | 적용할 대상·규칙을 정의 | 그 규칙으로 판단 가능한 범위를 설명 |
| 결과 | 핵심 관측을 보고 | 해당 관측이 답하는 질문을 회수 |
| 재해석 | 기존 예상 또는 관측의 의미를 제시 | 남은 대안 설명이나 설계 함의로 연결 |
| 제안 | 대응할 실패를 특정 | 효과 상태와 실패 가능 조건을 제시 |

### 5.5 시제와 인용 위치

- **정의·현재 주장:** “의미한다”, “구분한다”, “제안한다”.
- **완료한 절차·관측:** “제공하였다”, “대조하였다”, “관찰되었다”.
- **후속 작업:** “비교할 필요가 있다”, “확인해야 한다”.
- **문헌의 결과:** “○○는 …를 보고하였다”처럼 그 문헌의 관측임을 표시한다.
- **인용 위치:** 해당 주장 바로 뒤에 둔다. 여러 문헌을 한 문단 끝에 몰아 두어 어느 논문이 어느 주장을 지지하는지 흐리지 않는다.

## 7. 초고를 쓸 때의 우선순위와 점검표

### 7.1 집필 순서

1. **4·5장:** 실제로 수행한 설계와 평가 규칙을 먼저 확정한다.
2. **6장:** 표·사례를 바탕으로 세 질문에 답한다.
3. **7장:** 관측·대안 설명·문헌의 관계를 쓴다. 사후 진단은 그 상태를 표시한다.
4. **8·9장:** 실패 지점마다 대응과 검증 방법을 연결한다.
5. **2·3장:** 완성된 분석에 필요한 문헌과 질문으로 정리한다.
6. **1·10장과 초록:** 실제로 남은 기여와 결과에 맞춰 처음과 끝을 쓴다.

### 7.2 분량 배분의 편집 기준

확인한 자료에는 소논문의 공식 쪽수·글자 수 제한이 없다. 따라서 특정 분량을 필수 규정으로 제시하지 않는다. 다만 현재 원고는 **8장 대응 설계의 설명량이 6장 결과보다 많다.** 이 성격을 유지한다면 제목·초록·서론에서도 ‘사례 분석과 대응 설계’를 함께 밝혀야 한다.

실험을 중심에 두고 압축하려면 외부 산업의 상세 소개를 표에 모으고, 같은 한계 문장을 여러 장에서 반복하는 부분을 정리한다. 4·5장의 재현 정보와 6장의 증거를 먼저 줄이는 것은 권하지 않는다. 현재 목차를 유지하되 한두 문단으로 충분한 소절은 그 크기로 쓴다.

### 7.3 주장 범위 점검

### 8.3 검색·선정 원칙과 미확인 범위

기존 참고문헌을 출발점으로 삼아 논문 제목과 저자, ‘생성형 AI 포트폴리오 실험’, ‘ChatGPT 자산배분’, ‘설명 충실성’, ‘다중 턴 정보 제공’, ‘공통 모델과 동질화’를 중심으로 추가 검색하였다. 문장·구성 분석에는 학회·대학 저장소·연구기관의 원문을 우선 사용하였다. 국내 후보는 공개된 초록·목차 제공 화면으로 확인 범위를 제한하였다.
