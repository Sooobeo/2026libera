# 원초록 반영과 본실험 통합 기록

기준 자료는 사용자 PDF `C:/Users/Insun/Downloads/greengreen (1).pdf` 두 쪽 전체다. 파일에 포함된 학술 내용은 집필의 기준 자료로 사용했으며, 별도의 작업 지시로 취급하지 않았다.

본제와 부제는 원문의 물음표·하이픈·영문 표기까지 그대로 복원했다. 초록의 첫 두 문단은 원문 그대로 반영하고, 뒤의 실험 설명은 실제 수행한 다섯 조건·11개 산업·두 단계 자료 직접 제공으로 업데이트했다. 원안의 12개 산업을 오기라고 단정하지 않았다.

사용자의 추가 지시에 따라 현재 실험은 소논문의 본실험이다. 초록, 서론, 연구질문, 실험 장과 결론에서 이 위치를 통일했다. 현재 실험을 예비분석으로 두거나 전체 연구와 별개 단계로 낮추는 표현을 제거했다.

원래 컨셉인 전략적 이질성과 판단 품질, 과잉수렴, 분산된 GenAI 사용의 판단 누적 경로를 중심에 두었다. 본실험의 자료·설명·비중 대조 결과를 Workflow RAG의 계획·배분안 구성·점검과 수정 단계에 연결했다. 변경안 제출, 근거 개입 검사와 공동오류 복구는 이 대응 설계 안의 검토 기능으로 배치했다.

검색 근거의 단계별 첫 제공과 이후 유지, 무추가 근거 및 전체 적격 원문 조건, 실제 펀드 네 개와 조건부 수리 기준배분, 기대수익 손실·제약·새 문서 검색 및 비용 비교는 후속 확장 검증이다. 해당 비교를 이번에 실행했다거나 완화효과를 입증했다는 주장을 추가하지 않았다.

기존 수치표 11개와 참고문헌 41개, 원응답·완료 횟수·수정거리 및 비중은 보존했다. 원초록의 실무 배경 두 출처와 RAG 원논문을 공식 자료에서 재확인하여 참고문헌 세 개를 추가했다. 기존 결과 그림 5개는 그대로 두고 Workflow RAG 대응 설계도 1개를 추가했다.
