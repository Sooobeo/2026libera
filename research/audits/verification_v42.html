자료·구현 준비와 두 차례 검증

자료와 소프트웨어 준비를 검증한 기록이다. 실제 AI 예비·본실험은 0건이며, 사람의 독립 원문·설명 검토도 완료되지 않았다. 성공적인 연구 결과나 통계적 검정력을 인증하지 않는다.

미국 GICS 11개 산업, 공개 전망 4개(예비 2·본과제 2), ETF 11개의 같은 60거래일 수익률, 공통 S&P 500 산업 기준 비중을 연결했다. R1/R4 실행과 수정 전 비중 보존, 기계적 평가를 구현했다.

문서 검토는 정합성·논리성·소논문 주제와의 연결·근거를 점검했다. 과도한 전략 품질 표현, 계산기의 자동 수정으로 오해되는 문구, 예비 자료의 독립성 표현을 고쳤다. 두 차례는 같은 검토자가 수정 전후를 반복 확인한 것으로, 두 독립 연구팀의 재현을 뜻하지 않는다.

코드에서는 출처 ID 누락, 중복 JSON 키, 평가 파일의 분리, 사전 동결 대상과 실행 버전 기록, UBS에 없는 이유를 감점하는 문제를 수정했다. 엔진·통합 단위검사 25개, 별도 합성 통합 확인 22개 및 2차 방어 조건 7개를 통과했다. 합성 응답은 배선 검사용이며 AI 응답이나 AI 성능이 아니다.

원래 제안서·설계서·수행보고서 3개는 변경하지 않았다. 원본 해시와 HTML 링크 검사는 통과했다. 화면·인쇄 시각 검수는 이 기록의 인증 범위에 포함하지 않는다.

실제 실행까지 남은 순서는 모델 환경 선택·버전 고정 → 예비 실행 → 원문·설명 검토와 평가규칙 확정 → 자료·코드·모델 해시 동결 → 본과제 실행 → 사후 채점이다. 선정 모델은 현재 PC에 설치되지 않았으며 작은 모델로 자동 대체하지 않는다.
