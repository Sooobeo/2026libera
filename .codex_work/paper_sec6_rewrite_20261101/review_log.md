# 6절 재작성 검토 기록

검토 대상은 해결방안의 문장과 논증이다. 제안 효과를 새 실험으로 입증한 것은 아니다. 원래 요청의 두 차례에 추가 두 차례를 더하여 총 네 차례 검토한다.

## 대조 자료와 우선순위

- 연구 질문과 문제 경로: Downloads/LIBERA_소논문_최종결과반영_20261030.md의 1절 및 plan/문규리 제안서 상세_최종.html.
- 실제 완료된 입력·절차·평가 범위: plan/LIBERA_최종수행_실험설계서_20261030.html 및 원고 3~5절.
- 제안 동기의 근거: 원고 5.1~5.7절. 원제안서의 초기 설계는 최종 수행 사실을 대체하지 않는다.
- 외부 문헌은 판단 경로·검색·감독·평가 관점의 배경이다. 금융 과제에서 제안 효과를 직접 입증한 자료로 사용하지 않는다.

## 공통 판정 기준

| 항목 | 기준 |
|---|---|
| 정합성 | 공통 GenAI의 중간 정보 선택·해석이 후속 판단에 누적될 가능성에 대응하고, 기관별로 필요한 차이와 판단 품질을 함께 보존한다는 서론의 질문을 유지한다. |
| 논리성 | 관측된 한계, 기존 설계와 달라지는 점, 제안의 작동 방식, 평가 기준이 이어져야 한다. 기존에 하던 정보 제공·근거 기록·검사를 새 기능처럼 쓰지 않는다. |
| 인과성 | 초기 고착·검색 누락·공유 모델의 인과효과 또는 제안 효과가 이미 식별되었다고 주장하지 않는다. 최초 시점과 함께 노출·이력이 달라진 점, 실패 처리의 기여를 구분한다. |

## 사실과 제안의 대응

| 근거 | 재작성의 처리 |
|---|---|
| 모든 조건에 보유·위험·제약이 이미 제공됨 | 도입에서 명시. 기본 특성을 뒤늦게 추가한다는 설명을 배제. |
| R1~R3 동일 패킷에 산업별 전망 12항목 모두 포함 | 둘째를 실제 문서 갱신·충돌에 대응하는 실무 확장으로 제한. 검색 누락 진단이라고 하지 않음. |
| 이전 계획·응답·근거 모두 유지 | 첫째의 새 요소는 동일 가용정보에서 기존 AI 초안을 제외한 별도 재분석 경로임을 명시. |
| 근거 ID·사실값·시점·해석 기록과 외부 검사·수정 기회가 이미 존재 | 기록은 새 기능이 아닌 두 안 비교 자료로 활용. 계산·검사는 지원 절차로만 유지. |
| R1·R2 평균 과잉수렴, R3 유효율 우위이나 R0 대비 평균 손실 개선 없음 | R3 최적 단정 금지. 비교 기준을 미제공 조건으로 명시. |
| 기존 보유 적용과 외부 처리도 최종 차이 형성에 관여 | 재배분·근거 유지·제약 보류·실패 적용을 구분. |
| 원제안서는 자료 제공 단계·검색 방식·재검토 설계 원칙과 독립 검토를 확장 범위로 제시 | 독립 재분석, 쟁점별 재검색과 이전 단계 복귀, AI 노출 전 기관 사전 판단을 제안. |

## 1차 draft_v1 검토

독립 검토자 두 명이 세 항목을 모두 대조했다.

- 정합성: 조건부 적합. 독립안에 공통 시장정보를 명시하고, 추가 검색·사람 사전 판단은 통제 비교와 구분할 필요.
- 논리성: 수정 필요. 선택 기준, 비교 기준, 비용 및 추가 호출 통제가 더 분명해야 함.
- 인과성: 큰 비약 없음. 다만 ‘이번 수행 방식’에 한정하고 미제공 대비라는 손실 비교 기준을 명시할 필요.

반영: draft_v2에서 동일 시점의 허용된 공통정보·펀드정보, 명시적 선택 기준, 기존 기록의 재사용, 통제 과제와 실무 확장의 분리, 호출 예산·인력시간, 절차 전체의 효과라는 해석을 추가했다. 정보 교체 시 수리 기준배분 재계산도 명시했다.

## 2차 draft_v2 검토

두 독립 검토자 모두 정합성·논리성·인과성에 수정 필수 쟁점이 없다고 판정했다. 기존 입력·검사·수정과 새 제안의 구분, 동일 가용정보, 실무 확장 범위, 원인·효능 미입증의 제한을 재확인했다.

가독성 권고: 후속 통제 비교와 실제 운용자료 평가를 별도 문단으로 분리.

## 3차 추가 검토

앞선 1·2차 검토를 수행하지 않은 별도 검토자가 세 항목과 가독성·각주 범위를 다시 대조했다. 통제 과제에서 운용자의 재량 선택까지 들어가는지 모호하여, 호출 수를 맞춰도 선택 기준의 효과와 판단 경로의 효과가 섞일 수 있다는 수정 필수 항목을 발견했다.

반영: draft_v3의 통제 비교 문단에서 두 안의 선택·수정 규칙을 사전에 고정하고, 운용자의 사전 판단·재량 검토는 실무 시범 적용으로 구분했다. 독립안은 ‘해당 조건에서 그때까지 허용된 동일 정보’라는 점도 명확히 했다. 검토자가 재확인한 3차 최종판정은 세 항목 모두 통과였다.

추가 권고: 두 안의 일치를 정확성의 증거로 간주하지 않고, 유지 이유를 모델의 설명만으로 확정하지 않는다는 두 문장을 final.md에 반영했다.

## 4차 추가 검토

두 독립 검토자가 최종 DOCX의 실제 패키지와 final.md, 원자료를 대조했다. 정합성·논리성·인과성 모두 통과, 수정 필수 항목 없음으로 판정했다.

- 제목 및 본문 8개 문단(제목 포함 9개)이 최종 MD와 일치.
- 실제 Word 각주 참조·정의 1~5가 일치하고, 각주 내용이 최종 MD와 일치.
- 외부 원문 링크 6개가 각주 관계 ID의 HTTPS 대상으로 연결.
- footnotes 문서 관계 및 콘텐츠 형식 등록 정상.
- 통제 비교의 선택 규칙과 실무 재량, 정보·호출·인력 차이 구분 유지.
- 동일한 두 안의 정확성 보증, 유지 설명의 정보 반영 입증, 초기 고착·검색 누락·공유 모델·신규 해법의 효과를 단정하는 표현 없음.
- 인용 문헌은 배경 관점으로, 금융업무의 구체적 설계는 본고의 미검증 제안으로 구분.

검토 결론은 문장과 논증의 일관성 및 인과적 비약 여부에 관한 것이다. 네 차례 검토를 해법 효능의 네 차례 실험적 입증으로 해석하지 않는다.

## 최종 문서 표시 확인

Microsoft Word가 최종 DOCX를 읽기 전용으로 열어 각주 5개를 확인하고 PDF로 내보냈다. 선택된 Windows 런타임에 LibreOffice가 없으므로 이 PDF를 패키지 render_docx.py의 변환 입력으로 연결하여 페이지 PNG를 생성했다. 렌더 영수증의 DOCX SHA-256은 document_audit.json과 동일하다.

2개 페이지를 모두 열어 확인했다. 본문과 페이지 하단 각주가 정상 표시되며, 누락된 글자·잘림·겹침·제목의 장식선은 없다. 각주 원문 링크 6개는 실제 Word 하이퍼링크로 연결되어 있다. 최종 전달 대상은 각주를 포함한 DOCX 한 개다.
